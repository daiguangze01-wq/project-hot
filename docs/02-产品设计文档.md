# 产品设计文档（PRD）

> 一句话：**保留《热血英豪》的「装备 = 招式 + 全键盘 ZXCV 读招」，把视角改成 2.5D 斜俯视，用 3D 低多边形 + 像素贴图呈现，做成 PC 优先、服务器权威、公平付费的动作 MMO。**
>
> 数字/术语以 `docs/00-设计基线与术语.md` 为准；本文出现的数字若与 00 冲突，以 00 为准并提 decision request。

---

## 0. 结论摘要

- **核心差异**：2.5D 俯视 + 装备=招式 + 全键盘 ZXCV + 3D 像素 + 公平付费。市场上没有完全同类的现代产品；热血英豪/热斗传说老去，Lost Ark/RO/Tree of Savior 证明 2.5D 俯视 MMO 可行。
- **核心循环**：城镇接任务/匹配 → 战斗 → 掉落/成长 → 调整 Build → 更高难 PvE/排位 → 社交/交易/展示。
- **第一验证点**：M0 战斗原型（2 武器/2 核心/1 图/键盘-only）是否“像英豪、但更适合俯视”。
- **商业底线**：不卖属性、不做强度抽奖；靠外观/战令/创始人包/UGC 长期运营。
- **最大风险**：2.5D 俯视下的空战/高度可读性；全键盘 C+X 冲突；内容 treadmill；外观付费能否覆盖成本。

---

## 1. 愿景、定位与用户

### 1.1 愿景

让“装备改变打法、操作决定胜负”的动作 MMO 在 2.5D 俯视、像素美术、全键盘的形态下重新成立；老玩家找回英豪的读招与 Build，新玩家不用鼠标也能享受深度动作。

### 1.2 设计支柱

| 支柱 | 含义 | 设计落点 |
|---|---|---|
| 装备即 Build | 一件核心改变打法；收集为了表达 | 8 武器 × 12 核心 × 20 防具 × 符文 |
| 读招与连段 | 易上手、难精通；通用猜拳 | 防御/完美格挡/冲刺/击飞/受身/破防 |
| 2.5D 可读性 | 固定斜俯视也能看清 | 预警圈/剪影/高度/遮挡/键盘软锁定 |
| 公平长线 | 不卖属性；赛季/UGC/社区 | 外观/战令/创始人包；PvP 归一化 |

### 1.3 目标用户

| 用户 | 需求 | 我们提供 |
|---|---|---|
| 英豪/热斗/Lost Saga 老玩家 | 装备=招式、ZXCV、房间制 PvP、老友社交 | 经典布局、装备核心、1v1/3v3/8 人、公会 |
| 2.5D 动作 MMO 玩家（Lost Ark/RO/Tree of Savior） | Build 深度、副本、长线成长 | 12 核心/20 防具、4 副本/RAID、赛季 |
| 像素/低多边形爱好者（MapleStory/Hytale） | 有辨识度的世界、时装、截图/创作 | 3D 像素、斜俯视、外观/UGC |
| 竞技动作玩家 | 读招、排位、赛事 | 归一化 PvP、MMR、赛季、回放 |
| 内容创作者 | 素材、Build、社区 | 训练场、配装分享、UGC（S2） |

### 1.4 非目标

- 不做自由 3D 镜头/无缝开放大世界/自由飞行。
- 不做固定职业/传统战法牧。
- 不做 P2W/无保底强度抽奖/霸体特权。
- 不做鼠标依赖/写实 3A。
- 首版不展开剧情；只做任务框架。

## 2. 核心循环

```text
登录 → 城镇（社交/交易/打造/接任务）
  → 野外/副本/竞技场（匹配或组队）
  → 战斗（读招/连段/预警/掉落）
  → 经验/装备/材料/荣誉/赛季进度
  → 调整 Build（武器/核心/防具/符文）
  → 更高难 PvE / 排位 PvP / 赛季目标
  → 回城镇（社交/交易/展示）→ 下一轮
```

**单次会话目标**：至少完成一次「战斗 → 有意义掉落/进度 → Build 调整」。
**单局时长**：副本 8–15 分钟；RAID 15–25 分钟；PvP 3–5 分钟；野外 10–30 分钟。

## 3. 2.5D 相机与全键盘操作

### 3.1 相机

| 项 | 值 |
|---|---|
| 视角 | 固定 45–55° 斜俯视 |
| 投影 | 正交（默认） |
| 正交尺寸 | 7–9（M0 可校准 6–8） |
| 角色占屏高 | 70–90px @1080p（约 6.5–8.3%；有效高度 1.8m、size 7–9、pitch 50°；M0 校准） |
| 缩放 | 0.8–1.2×；键盘 `+/-` |
| 平移 | 有限跟随/平移；不旋转 |
| 鼠标 | 不参与战斗/镜头 |
| 遮挡 | 屋顶/树冠/高墙淡出；角色轮廓/影子保留 |
| 边缘 | 目标/队友/危险指示器 |
| 锁定 | Z 软锁定最近敌人（120° 锥，14m）；Q/Tab 切换 |

**可读性验收（首版）**：

| 距离 | 必须识别 | 通过标准 |
|---|---|---|
| 6m | 自己/敌人/装备/预警 | ≥90% 测试者 1 秒内识别 |
| 10m | 敌人/预警/队友 | ≥85% |
| 14m | 轮廓/方向/危险 | ≥80% |
| 20/30m（zoom-out size 15/23） | 战术/轮廓 | ≥70%，不作战斗验收 |

### 3.2 经典布局（默认）

| 输入 | 功能 | 说明 |
|---|---|---|
| 方向键 / WASD | 8 方向移动 | 屏幕相对；角色朝移动方向 |
| 双击方向 | 冲刺 | 短 i-frame；Shift 可选替代 |
| Z | 瞄准 / 软锁定 / 特殊技修饰 | 轻按面向最近敌人；按住 + X/C |
| X | 重击 | 击飞/破防/终结；完美防御后反击 |
| C | 轻击 | 连段起手；拾取用 F |
| V | 跳跃 | 跃击/短滞空；V+C / V+X 空中攻击 |
| C+X | 防御 / 格挡 | Space 可选替代；完美格挡 100ms |
| Z+C / Z+X | 特殊技 1/2 | 核心定义；消耗 MP |
| Z+方向+C / Z+方向+X | 特殊技 3/4 | 4 个指令技中的后两个；消耗 MP |
| Z+X+C | 必杀 | 消耗必杀槽 |
| 双击方向+C/X | 冲刺攻击 | 突进/位移 |
| F | 交互 / 拾取 | 键盘-only |
| Q/Tab | 切换锁定目标 | 可选 |
| +/− | 缩放 | 默认固定 |

### 3.3 现代布局（可选）

| 输入 | 功能 |
|---|---|
| Z | 轻击 |
| X | 重击 |
| C | 技能 1 / 投技 |
| X+C | 技能 2 |
| 方向+C | 技能 3 |
| 方向+X+C | 技能 4 |
| Z+X+C | 必杀 |
| Alt | 软锁定最近敌人（现代布局） | 与经典 Z 软锁定等价 |
| V | 跳跃 |
| Space | 防御 |
| Shift | 冲刺 |
| F | 交互 |
| Q/Tab | 切换目标 |
| +/- | 缩放 |

> 两套布局都全键盘、无鼠标；键位可重映射；C+X 冲突有 Space 替代；训练场检测 rollover。
>
> 现代布局软锁定 = Alt（Z 已让给轻击），Q/Tab 切目标；必杀 Z+X+C 支持顺序输入 Z→X→C（≤250ms），低 rollover 键盘可用。
>
> **方向组合判定**：方向键在 C/X 前 ≤3f（50ms）内按下 → 方向版（特殊 3/4、现代技能 3/4）；方向已按住 >3f（移动中）→ 基础版（特殊 1/2、现代技能 1/2）。优先级：C+X 防御 > Z+X+C 必杀 > 新鲜方向组合 > 基础特殊 > 普通攻击。自检覆盖方向+Z+C、方向+Z+X、方向+C、方向+X+C。

### 3.4 键盘-only 规则

- 战斗、镜头缩放、菜单、匹配、聊天、副本/PvP 全流程不需要鼠标。
- UI 以键盘导航为默认；鼠标仅可选便利。
- 远程/瞄准技能用软锁定/朝向/锥形自动瞄准，不做鼠标自由瞄准。
- 键位冲突可检测、可重映射、可恢复默认；支持 6KRO/全键无冲。

## 4. 战斗系统

### 4.1 状态机

```text
Idle → Move → Dash → Jump/Air → Attack/Skill → Hitstun → Knockdown → Getup
  ↘ Guard → PerfectGuard → GuardBreak
  ↘ Grab → Throw
  ↘ Hurt → Airborne → Juggle → Land
```

### 4.2 资源

| 资源 | 首版基准 | 作用 | 恢复 |
|---|---|---|---|
| HP | 500 | 生存 | 药水/治疗/复活 |
| MP | 100 | 特殊技/必杀（部分） | 时间/命中/装备 |
| 架势 | 300 | 防御消耗；归零破防 | 时间/完美格挡 |
| 必杀槽 | 100 | Z+X+C 必杀 | 造成/承受伤害、连段 |

> 锁定 14m；冲刺 i-frame 2–6f；完美格挡 100ms；破防 1.2s；反击 0.4s；首版基准，M0 调参。

### 4.3 通用规则

- **防御**：C+X；正面 120° 锥；背后攻击 +20% 伤害/破防。
- **完美格挡**：本地 100ms/在线 150ms（M0 验证）内 C+X；0 HP 伤害；可 X 反击。
- **冲刺**：双击方向；短 i-frame 2–6f；Shift 可选。
- **跳跃**：V；跃击/空中攻击；落地硬直。
- **投技**：由核心定义（Z+方向+C 等），不是通用键；不设全员通用抓取。
- **受身**：倒地后按方向/防御减少硬直。
- **连段衰减**：同一套连段伤害递减；防止无限连。
- **高度**：地面/空中两态；影子/缩放/高度条/命中特效；空中追击 1–2 段。
- **PvP 归一化**：装备数值压缩；核心机制保留；赛季调参。

**2.5D 专项规则（首版）**：

- 8 方向对角线归一化；技能判定吸附 8 向；出手自动面向 45° 扇区最近目标，方向输入可覆盖；脚下朝向环。
- 屏外攻击用边缘指示；高墙/树冠淡出/剖切；角色轮廓/影子保留。
- Boss 预警三通道：地板色块 + 读条 + 音效；红=即伤、黄=延迟、蓝=可反制；窗口 0.5–1.5s；多段机制给安全区。

**防御时序预算（首版，M0 验证）**：

- 完美格挡：本地/离线 100ms；在线 150ms（9f）+ 服务器 1 tick 容差；用输入时间戳，不只看按键 tick。
- 攻击命中盒回放 ≤200ms；防御交互单独 cap 150ms/defender-favoring；若 30Hz 仍不稳定，1v1/3v3 排位默认 60Hz。
- M0 验收：RTT 80/100ms 下完美格挡成功率 ≥70%、误判 ≤5%；不达标调窗口/60Hz/回放 cap。

| 轻击 3 | C→C→C | 10f | 4f | 20f | 45 | 22f | 0 | 后摇前 6f |
| 重击 | X | 18f | 5f | 24f | 80 | 28f | 0 | 后摇前 8f |

### 4.5 伤害公式

```text
Damage = Base
       × (1 + Atk / 100)
       × (1 - Def / (Def + 300))
       × ComboScale
       × PosMod
       × ElementMod
       × PvPMod
```

- `ComboScale`：1.0 / 0.9 / 0.8 / 0.7 / 0.6 / 0.5（最低 0.5）。
- `PosMod`：正面 1.0；侧面 1.1；背面 1.2。
- `ElementMod`：克制 1.2；被克 0.8；无 1.0。
- `PvPMod`：0.75（首版）；装备归一化后再乘。
- 防御：格挡时 HP 伤害 ×0.2、架势伤害 ×1.0；未格挡命中按基础架势伤害；架势归零破防 1.2s。
- 完美格挡：HP 伤害 0；架势 +10；反击窗口 0.4s。

**示例**：Base 80、Atk 40、Def 100、ComboScale 0.9、背击 1.2、PvPMod 0.75：
`80 × 1.4 × 0.75 × 0.9 × 1.2 × 0.75 ≈ 68`。

### 4.6 PvE / PvP 差异

| 项 | PvE | PvP |
|---|---|---|
| 数值 | 装备生效 | 归一化 |
| 命中 | 偏攻击者 | 服务器回放 + 偏防御窗口 |
| 连段 | 可较长 | 衰减更强、防止无限连 |
| 复活 | 副本次数/队友复活 | 回合/重生 |
| 匹配 | 4 人/8 人 | MMR/段位 |
| 反作弊 | 服务器权威 | 回放/审计/举报 |

**PvP 归一化（首版）**：

- HP/攻防/冷却按等级模板；装备 PvE 数值压缩到 ±5% 以内；武器/核心机制保留。
- 传说独特机制在 PvP 中标准化；赛季调参；不卖属性。
- 目标：同水平玩家胜负由读招/配合决定，不由装备评分决定。

## 5. 装备与 Build

### 5.1 槽位

| 槽位 | 内容 | 影响 |
|---|---|---|
| 武器 | 8 原型 | 基础 C/X 动画/范围/速度 |
| 战斗核心 | 12（1.0） | 4 指令技 + 必杀 + 被动 |
| 防具 ×3 | 头/身/腿 | 防御/HP/抗性/套装/外观 |
| 符文 ×2 | 被动/词条 | 攻速/暴击/减耗/机制微调 |
| 外观 | 时装/皮肤 | 纯外观 |

> 共 8 件：武器 1 + 战斗核心 1 + 防具 3 + 符文 2 + 外观 1。外观可覆盖防具/武器外观，但不改判定。

### 5.2 武器原型（8）

| 武器 | 定位 | 特点 | 弱点 |
|---|---|---|---|
| 剑 | 均衡 | 中距离/中速度/易上手 | 无突出 |
| 巨剑 | 重击/破防 | 高伤/长判定/霸体技 | 慢/易被绕背 |
| 长枪 | 距离/控制 | 突刺/扫击/击退 | 近身弱 |
| 双刀 | 连段/机动 | 高攻速/冲刺/背刺 | 短/低伤 |
| 拳套 | 近身/投技 | 快/抓取/连段 | 短/怕范围 |
| 弓 | 远程/风筝 | 软锁定/穿透/陷阱 | 近身弱 |
| 法杖 | 范围/控制 | AoE/减速/护盾 | 慢/耗蓝 |
| 链刃 | 中距/拉扯 | 拉近/横扫/位移 | 操作难 |

### 5.3 战斗核心（12；示例 4 个）

| 核心 | 主题 | 4 技能 | 必杀 | 被动 | 适配 |
|---|---|---|---|---|---|
| 雷鸣 | 雷/突进/感电 | 雷突、落雷、电场、闪身 | 雷狱 | 感电叠层 | 双刀/长枪 |
| 霜狱 | 冰/控制/区域 | 冰墙、霜环、冻结、护盾 | 极寒领域 | 减速增伤 | 法杖/巨剑 |
| 影袭 | 背刺/瞬步/分身 | 瞬步、背刺、影分身、烟雾 | 影杀阵 | 背击加成 | 双刀/拳套 |
| 守御 | 格挡/反击/保护 | 盾击、格挡姿态、嘲讽、护盾 | 不动堡垒 | 完美格挡回架势 | 巨剑/长枪 |

其余 8 个：火/毒/风/召唤/陷阱/连射/抓投/支援，在 1.0 前定稿。

### 5.4 防具/符文/稀有度

- 20 套防具：轻/中/重三类；套装 2/3 件效果（防具仅 3 槽，不做 4 件套）；外观可覆盖。
- 分层：轻甲 7 套（移速/闪避/攻速）、中甲 7 套（均衡/技能）、重甲 6 套（防御/格挡/仇恨）；10 套 PvE、10 套 PvP/赛季。
- 符文：2 槽；攻速/暴击/减耗/移速/机制微调；不卖。
- 稀有度：普通/稀有/史诗/传说；传说给**独特机制**，不给纯数值碾压；PvP 中标准化/受限，机制符文 PvP 限 1–2 条。
- 强化：+0–+10；不破碎；材料来自 PvE；不卖强化材料。
- 无随机词条赌博（首版）；避免 P2W/军备竞赛。
- PvP 归一化：装备数值压缩；核心机制保留。

### 5.5 示例 Build

**疾风双刀（影袭）**
- 武器：双刀；核心：影袭；防具：轻甲套；符文：攻速 + 冲刺冷却。
- 打法：Z 软锁定 → 冲刺绕背 → C 连段 → Z+C 瞬步取消 → 必杀收割。
- 弱点：正面硬拼弱；怕防御/范围控制。

**不动堡垒（守御）**
- 武器：巨剑；核心：守御；防具：重甲套；符文：格挡回架势 + 减伤。
- 打法：C+X 防御/完美格挡 → X 反击 → Z+X 盾击 → 必杀开团。
- 弱点：机动差；怕远程/破防。

### 5.6 平衡杠杆

- 帧数据（前摇/判定/后摇/取消窗口）。
- 伤害/连段衰减/资源消耗。
- 范围/位移/i-frame/霸体帧。
- 冷却/MP/必杀槽。
- 赛季调参 + 模拟 + 玩家数据；目标：没有“必选核心”，只有“克制/搭配”。
