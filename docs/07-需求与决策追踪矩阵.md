## 1. ID 规则

| 类型 | 格式 | 示例 | 说明 |
|---|---|---|---|
| 需求 | `REQ-<area>-###` | `REQ-CTL-001` | area：VIS/CTL/CBT/MMO/ART/TECH/BIZ/PROC/QA |
| 决策 | `ADR-###` | `ADR-004` | 正文在 `docs/decisions/` |
| 任务 | `TASK-###` | `TASK-011` | 看板在 `docs/backlog.md` |
| 测试/验收 | `TEST-###` | `TEST-010` | 可映射到 QA 用例/原型验收 |
| 运行 | `RUN-YYYYMMDD-##` | `RUN-20261017-01` | 在 `docs/runs/` |
| 评审 | `REV-###` | `REV-001` | 在 `docs/_review/` |

状态：`planned` → `drafted` → `reviewed` → `accepted` → `implemented` → `verified`；`blocked`/`deprecated` 需说明。
