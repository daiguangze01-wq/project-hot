# 2.5D 俯视像素美术风格指南（草稿）

> TASK-015 产出，待合并进 `docs/04-3D像素美术风格指南.md`。数字以 [`docs/00`](../00-设计基线与术语.md) 为准；本文新增数字标「建议值」，需风格测试后由 Art Lead + Human 确认。基线张力不自行修改，集中列在 §4.2 与 §12.4。

## 0. 结论

- **路线**：3D 低模 + 手工像素贴图 + 45–55° 正交斜俯视；不做 voxel、不做全屏像素化、默认不做 2D billboard（ADR-010）。
- **像素感来自资产**：密度 64–128px/m、32–64 色板、点采样、8–12fps 阶梯、像素 VFX/UI；关掉后处理仍应像像素。
- **可读性优先**：角色屏上 58–74px 时，仍要分辨 8 种武器、4 档稀有度、Boss 预警类型。
- **管线**：Blockbench/Blender → Aseprite/Substance → URP → 导入校验 → Addressables；33 骨共享骨架，按武器原型复用动画。
- **先验证再量产**：风格测试（1 角色+1 环境+3 装备+1 Boss）通过后才放量。预算 EA ≈ 87 / 1.0 ≈ 174 人月（±30%），外包 33–35%。

## 1. 风格定义

### 1.1 一句话

**「2.5D 斜俯视的低多边形像素戏台」**：3D 低模承载朝向、遮挡、高低差与换装；手工像素贴图与阶梯动画提供冒险岛式辨识度；相机固定、光照烘焙、材质无 PBR。

### 1.2 六个判定维度

| 维度 | 是 | 不是 | 判定 |
|---|---|---|---|
| 几何 | 低多边形，四边形为主，3–8k tris | voxel：统一体素网格堆叠 | 是否由同一体素单位构成 |
| 呈现 | 3D 资产 + 像素贴图 | 2D billboard sprite（默认） | 转向/换装是否需重画 |
| 像素感 | 资产级：密度/色板/点采样/阶梯 | 全屏像素化后处理 | 关后处理后是否仍像像素 |
| 光照 | 烘焙 AO + ramp，贴图内画光影 | PBR：法线/粗糙度/金属度 | 材质是否只有 albedo/emission |
| 相机 | 固定 45–55°、正交、不旋转 | 自由 3D 镜头 | 有无旋转/鼠标镜头 |
| 动画 | 8–12fps 阶梯（保持帧） | 60fps 全程平滑 | 姿态是否按帧保持 |

### 1.3 三支柱

1. **可读性优先**：任何细节让剪影变糊、预警变弱，就删。
2. **剪影即身份**：玩家先认出「拿巨剑的」，再认出「穿什么」；装备必须改外轮廓。
3. **手作感**：像素是画出来的，不是 3D 渲染后压出来的；禁用降分辨率滤镜冒充。

### 1.4 像素感五要素

| 要素 | 参数 | 说明 |
|---|---|---|
| 贴图密度 | 角色/装备 64–128px/m；环境 32–64px/m | 角色密度翻倍，从背景里跳出来 |
| 色板 | 32–64 色/资产；全局基础 8 色 | 禁纯黑纯白；阴影带色相 |
| 采样 | 点采样；mip 0–1；不开各向异性 | 避免远景糊成灰块 |
| 动画 | 8–12fps 阶梯，默认 10fps | 60fps 下每张保持 6 帧 |
| 边缘 | 屏幕空间 1px 描边；取色板暗色 | 不随距离加粗；不烘进贴图 |

> Hytale 官方建模指南明确「不用 PBR 工作流、把光影/AO/高光画进贴图、避免纯黑纯白、阴影带色」，角色/饰品 64px 每单位、道具/方块 32px 每单位，贴图为 32 的倍数，单轴拉伸 0.7–1.3×（[来源](https://hytale.com/news/2025/12/an-introduction-to-making-models-for-hytale)）。本文采用同一套贴图纪律，不采用其体素几何。

## 3. 路线对比

### 3.1 四条路线

| 路线 | 几何 | 相机 | 优点 | 缺点 | 成本指数 | 结论 |
|---|---|---|---|---|---|---|
| **A. 3D 低模+像素贴图** | 3–8k tris | 正交斜俯视 | 朝向/遮挡/高度/换装全要；动画可复用；外包成熟 | 需贴图与描边规范；不是「纯像素」 | 1.0 | **选定** |
| B. 2D billboard | sprite 面片 | 正交斜俯视 | 单帧表现力最强 | 8 方向重画；换装爆炸；遮挡/高度差 | 2.5–3.5 | 仅作对照 |
| C. Voxel | 体素网格 | 任意 | 强 3D 像素辨识；可破坏自然 | 装备改形要重做；剪影块状；难做 2.5 头身 | 2.0–3.0 | 不采用 |
| D. 全屏像素化 | 常规 3D | 任意 | 最便宜 | 「糊掉的 3D」；UI 糊；边缘闪烁 | 0.4 | 不采用 |

### 3.2 为什么 billboard 不行

- 剑原型约 45 个动作；billboard 每动作 8 方向 × 10 帧 = 80 帧 → **3,600 帧/角色**。换一件披风，全部帧重画。
- 3D 换装只换网格与贴图，动画零重做——这是选 A 的决定性理由。
- 例外：远景人群、天空、植被十字面片、部分 VFX 贴片可用 billboard；低 FOV 透视（35–45°）仅作测试变体，默认仍正交（ADR-002）。

## 4. 相机与构图

### 4.1 参数

| 项 | 值 | 说明 |
|---|---|---|
| 俯角 | 45–55°，默认 50° | 低于 45° 遮挡重；高于 55° 变地图、角色变扁 |
| 偏航 | 默认 45°（等距感），测试变体 0° | 不开放给玩家 |
| 投影 | 正交（默认）；测试变体 FOV 35–45° | 见 §4.2 |
| 正交尺寸 | 7–9，默认 8（城镇 8.5 / 副本 7.5 / 竞技场 8） | 按场景微调 |
| 缩放 | 0.8–1.2×，键盘 `+/-`，步进 0.1 | 有效值钳制 7–9 |
| 平移 | 跟随 + ±3m 缓冲；不旋转、无相机碰撞 | — |
| 鼠标 | 不参与镜头；战斗中隐藏光标 | 与 `docs/00` §4.1 一致 |
| 锁定 | Z 软锁定 120° 锥；Q/Tab 切换 | — |

### 4.2 占屏口径与缩放钳制（待决）

| 正交尺寸 S | 可视高度 | 1.5m 角色世界高度占比 | 俯角 50° 压缩后屏上高度（1080p） |
|---|---|---|---|
| 7 | 14m | 10.7% | 74px |
| 8 | 16m | 9.4% | 65px |
| 9 | 18m | 8.3% | 58px |

- 表中按 Unity `orthographicSize`（半高）计；若 S 指可视全高，可视高度减半、占比翻倍（未压缩 16.7–21.4%，压缩后 10.7–13.8%）——此读法更接近基线。两种定义必须在 TDD 里写死。
- 在上述半高定义下，基线「占屏 8–12%」按**世界高度 / 可视高度**口径成立（8.3–10.7%）；按**渲染后屏上高度**口径（乘 cos50°≈0.64）为 5.4–6.9%，低于基线，两口径差约 35%。
- 处理：可读性测试一律按保守口径 **58–74px**；请 Tech Lead 在 M0 定 TDD 口径。若采用渲染口径，需把角色提到 1.8–2.2m 或把 S 降到 5.5–6.5——这会改 `docs/00` §3.1，属基线变更，须 ADR + Human，**本文不改**。
- 缩放：输入 z ∈ [0.8, 1.2]，有效尺寸 `clamp(S/z, 7, 9)`。默认 S=8 时 z ∈ [0.89, 1.14] 线性，超出即钳制；若要完整行程需放宽正交区间（Q5）。

### 4.3 构图

| 规则 | 值 |
|---|---|
| UI 安全框 | 左右 8%、上下 12% 不放关键战斗信息 |
| 战斗焦点 | 屏幕中心 60%×60% 承担主要战斗 |
| 地面网格 | 2m；S=8 时横向 135px、纵向约 103px（sin50°≈0.77） |
| 地面预补偿 | 纵深按 0.77 压缩设计 |
| 高对比地面 | 角色脚下 1.2m 内禁止强花纹/强反光 |
| 引导 | 用地面明度梯度引路，不堆箭头 |

### 4.4 遮挡与屋顶淡出

| 项 | 规则 |
|---|---|
| 触发 | 遮挡物高 ≥2.5m，且挡住角色 30% 以上 |
| 表现 | 抖动（dither）降到 25–35%，0.25–0.3s；不用整体半透明 |
| 保留 | 角色 1px 描边、影子、地面预警圈、掉落高亮 |
| 不淡出 | 掩体、边界墙、可交互机关——避免「能不能走」误判 |
| 室内/树冠 | 进体积后整组淡出，离开 0.2s 恢复；树干不淡出 |

### 4.5 高度表达（四件套缺一不可）

影子 + 缩放 + 高度条 + 落地特效。

| 离地 | 影子缩放 | 影子不透明度 | 附加 |
|---|---|---|---|
| 0m | 100% | 60% | — |
| 0.5m | 92% | 50% | — |
| 1.5m | 78% | 38% | 高度条 |
| 3m | 60% | 25% | 高度条 + 落点圈 |

### 4.6 边缘指示

24×24px 图标 + 12px 数字，贴屏幕内边距 4–6%。颜色：目标黄白、敌人红、队友绿、危险橙、掉落青。同屏 ≤8 个，按威胁排序，其余折叠计数。不用光标指向，用锁定框（4 角括号）标当前目标。

## 5. 角色与装备

### 5.1 比例

2.5–3 头身；头高占身高 33–40%；手/脚放大 1.2–1.4×。基准身高 1.5m（`docs/00` §3.1），含帽/角可到 1.8–2.0m。站姿略外八、武器外露，保证斜俯视下不被身体挡住。

### 5.2 技术预算

| 项 | 值 |
|---|---|
| 三角面 | 3–8k（基础体型 3.5k + 装备 ≤4.5k） |
| 骨骼 | 33 骨：root/pelvis/spine×2/chest/neck/head/jaw、shoulder/upperarm/forearm/hand ×2、thigh/calf/foot/toe ×2、cape×3、weapon_r/l、tail×2、accessory×2 |
| 贴图 | 64–128px/m；角色图集 512²（EA）→1024²（1.0 高端皮肤）；单件装备 128² |
| 色板 | 32–64：皮肤 8 / 布料 10 / 金属 8 / 皮革 6 / 发光 4 / 描边 3 |
| 材质 | ≤2/角色；金属高光画进贴图 |
| 描边 | 屏幕空间 1px；取色板暗色，不用纯黑 |
| LOD | LOD0 100% / LOD1 50% / LOD2 25%，角色 ≥2 级 |

### 5.3 斜俯视剪影五要素

| 要素 | 作用 | 约束 |
|---|---|---|
| 帽子/头饰 | 最高点，最先被看到 | 改变头顶轮廓，套间高差 ≥8px |
| 肩甲 | 最宽点，决定体型 | 单/双侧外扩，宽差 ≥10px |
| 武器 | 方向与长度 | 外伸 ≥身宽 0.6×，不与身体重叠 |
| 披风/背饰 | 动势与身份 | 侧/后向飘出，静止也保留轮廓 |
| 尾巴/挂件 | 个性 | 可摆动，base pose 必须外露 |

规则：**每套装备至少改变 2 个要素**；只改颜色不算换装。

### 5.4 八武器原型的视觉区分

| 原型 | 长度/体量 | 剪影关键 | 攻击弧 | 65px 下的区分点 |
|---|---|---|---|---|
| 剑 | 1.0–1.2m 直刃 | 单侧直线 + 护手 | 120° 横斩 | 中等直线、有护手 |
| 巨剑 | 1.6–1.9m 宽刃 | 宽 ≥肩宽 1.5×，可扛肩 | 180° 大弧 | 最宽、最高点 |
| 长枪 | 2.0–2.4m 细杆 | 超长直线 + 枪尖 | 直线突刺 | 最长、近水平 |
| 双刀 | 0.5–0.7m ×2 | 双手各一、反握 | 快速交叉 | 双端点、最短 |
| 拳套 | 手部 1.4× | 无外伸武器、拳大 | 近身连击 | 无外伸、重心低 |
| 弓 | 1.2m 弧 | 弧形 + 弦 | 拉弓/抛射 | 弧形、侧持 |
| 法杖 | 1.5–1.8m 杆 | 顶端发光晶体 | 挥击/施法 | 顶端发光点 |
| 链刃 | 刃 0.6m + 链 2m | 拖尾曲线 | 弧线/回收 | 动态曲线、不规则 |

判据：8 个原型缩到 65px、去色成单色剪影，3 秒识别率 ≥80%（§11）。

### 5.5 稀有度色

| 稀有度 | 主色 | 辅色 | 非颜色冗余 |
|---|---|---|---|
| 普通 | #C9CDD4 | #8A9099 | 无角标 |
| 稀有 | #4FA3FF | #2D6FBF | 1 角标 |
| 史诗 | #B36BFF | #7A3FBF | 2 角标 + 微光 |
| 传说 | #FFB347 | #B36B12 | 3 角标 + 粒子 |

色相不单独承载信息：角标数 + 边框形状 + 发光强度同步变化。稀有度只影响表现，不影响数值（REQ-BIZ-001）。

### 5.6 模块化插槽

| 插槽 | 挂点 | 面数预算 | 备注 |
|---|---|---|---|
| 头（帽/发/脸） | `head` | 400–900 | 与脸/发型互斥 |
| 肩 L/R | `shoulder_l/r` | 200–500 | 可单侧 |
| 背（披风/翼/尾） | `spine_02` | 300–1,200 | 需 2–3 副骨 |
| 主手 | `hand_r` | 300–2,000 | 含 `weapon_r` 挂点 |
| 副手 | `hand_l` | 300–1,500 | 盾/副武器/空 |
| 胸/腰/腿/脚 | `chest`/`pelvis`/`thigh`/`foot` | 各 300–800 | 防具三件 |
| 挂件 ×2 | `belt` | 50–150 | 腰饰/符文 |

同屏可渲染模块 ≤12；超出优先隐藏挂件。所有插槽共用骨架与挂点名，新增插槽须 Art + Tech 双签。

## 6. 环境与高度

### 6.1 网格与预算

| 项 | 值 |
|---|---|
| 网格 | 2m 对齐；模块按 2m 排布 |
| 模块面数 | 1–5k；装饰件 ≤500 |
| 贴图 | 128–256px；密度 32–64px/m |
| kit 规模 | 每套 80–150 模块（地板/墙/柱/台阶/桥/悬崖/屋顶/装饰/可破坏） |
| 材质/LOD | ≤1 材质/模块；环境 2 级 LOD，远景合并 |

### 6.2 高度层与通行

| 高差 | 行为 | 表现 |
|---|---|---|
| 0–0.3m | 自动踏步 | 脚部 IK 微调，不切动画 |
| 0.3–0.8m | 需跳跃 | 起跳/落地动画 + 边缘亮线 |
| 0.8–1.2m | 跳跃上限 | 亮线加粗 + 跳台提示 |
| >1.2m | 不可直接通行 | 需坡道/梯/跳台；悬崖暗线 |

> 跳跃高度与阈值由战斗原型确认（`docs/00` 未定），本节为建议值，待核实。

### 6.3 台阶 / 桥 / 悬崖

- **台阶**：单级 ≤0.3m、宽 ≥2m；踏面比立面亮 10–15%，保证阶数可数。
- **桥**：宽 ≥4m；栏杆 0.9m（低于角色 60%）不遮躯干；影子投桥面而非地面。
- **悬崖**：上沿 1px 亮线 + 下沿暗线；落差 ≥2m 加风向粒子/落石提示。
- **坡道**：≤30°，条纹材质提示方向。

### 6.4 阴影与边缘高亮

| 项 | 规则 |
|---|---|
| 主光 | 固定方向光，俯角 50°、方位 135°，不随相机 |
| 烘焙 AO | 0.4–0.6，只烘环境不烘角色 |
| 实时阴影 | 仅角色/动态物，投射体 ≤16；图 1024–2048 |
| 边缘 | 可行走 1px 亮线；不可行走 1px 暗线 |
| 色温 | 5500–6500K；夜晚调色，不重做贴图 |

### 6.5 遮挡（环境侧）

室内默认隐藏屋顶，按房间分组切换；高装饰用 §4.4 抖动淡出；可穿门洞用暗色内凹 + 地面路径引导。**禁止半透明墙表示不可通行**：不可通行必须实心 + 暗线。

### 6.6 可破坏物

| 档 | 体量 | 碎片 | 生命期 | 掉落 |
|---|---|---|---|---|
| 小 | ≤0.5m | 4 个像素碎片 | 0.8s | 无 |
| 中 | 0.5–1.5m | 6 个 | 1.2s | 材料 |
| 大 | 1.5–3m | 8 个 + 尘土 | 1.5s | 材料/掩体变化 |

碎片用 sprite 不做刚体；可破坏物必须「看起来能打」：裂纹、缺角、偏暗至少其一。

## 7. 动画与 VFX

### 7.1 帧率与阶梯

| 项 | 规则 |
|---|---|
| 基准 | 10fps 阶梯（可选 8/12）；60fps 下每张保持 6 帧 |
| 换算 | `docs/00` §3.5 的 60fps 帧数据 ÷6 取整：轻击前摇 8f≈1 张，重击 18f≈3 张 |
| 姿态 | pose-to-pose 保持；姿态不插值，位移可插值 |
| 预备 | 2–4 帧（60fps 计）；阶梯后落为 1 张预备姿势，重击取上限 |
| 转身 | 8 方向 45° 阶梯；仅朝向插值 0.1s |
| 混合 | 上下半身分离；技能走上半身 additive |

### 7.2 打击感

| 项 | 值 |
|---|---|
| 命中停顿 | 50–100ms；轻击 50–60，重击 80–100，必杀 100 |
| 屏震 | 2–6px，80–150ms，指数衰减；可关闭 |
| 受击闪白 | 1–2 帧，只闪贴图不闪描边 |
| 顿帧 | 双方同停，被击方多停 1–2 帧 |
| 特效分层 | 闪光 1–2 帧 → 火花 4–6 帧 → 残影 6–8 帧 |

### 7.3 动画预算与复用

每武器原型 40–48 clips：移动 8、受击 6、死亡 3、表情 6、技能 20–24（EA）/24（1.0）。

- 8 原型 = 360 clips（1.0）；防具/外观**不新增动画**。
- 共享骨架 + 按原型覆盖：同原型不同外观只换网格/贴图。
- 战斗核心技能走 additive 上半身，不重做全身。

### 7.4 VFX 规范

| 项 | 规则 |
|---|---|
| sprite | 64–128px，8–12 帧，点采样，不生成 mip |
| 帧率 | 10–12fps，与角色一致 |
| 混合 | 加法用于发光/能量；Alpha 用于烟尘/碎片 |
| 层级 | 地面预警（最底）→ 角色 → 命中 → 前景（最上） |
| 数量 | 同屏 ≤120 quad；超出合并为序列 |
| 颜色 | 取自全局色板，不新建高饱和色 |

### 7.5 预警 / 命中 / 落地 / 高度

| 类型 | 规格 |
|---|---|
| 预警圈 | 提前 0.5–1.5s；外圈先出、内部填充；危险越高填充越快 |
| 形状 | 圆（范围）/ 扇（正面锥）/ 直线（冲锋）/ 矩形（持续） |
| 命中 | 落点 + 命中点双层；AOE 必显边界 |
| 落地 | 环形 1 帧 + 尘土 6 帧；高度 ≥2m 加落点圈 |
| 高度 | 与 §4.5 联动；空中目标脚下必须有影子 |

### 7.6 颜色语言

| 颜色 | 含义 | 冗余 |
|---|---|---|
| #E5484D 红 | 致命/高伤 | 三角尖刺 |
| #F28C28 橙 | 范围/持续 | 同心圆 |
| #F2C94C 黄 | 击飞/控制 | 向上箭头 |
| #4FA3FF 蓝 | 冰/减速/友方 | 六边形 |
| #B36BFF 紫 | 暗/诅咒/精英 | 裂纹 |
| #4CC38A 绿 | 治疗 | 十字 + 上升粒子 |
| #2F7D5A 暗绿 | 毒 | 气泡 |
| #F2F2F2 白 | 物理/通用 | 无 |

红/绿对必须叠加 ≥25% 亮度差与形状差；Boss 大招用「全屏压暗 + 中心高亮 + 文字」三重冗余。

## 8. UI

| 项 | 规则 |
|---|---|
| 字体 | 像素字体；中文 12px 点阵，数字等宽；关键数字 16–24px |

## 9. 管线

### 9.1 流程

```mermaid
flowchart LR
  A["概念/情绪板"] --> B["Blockbench 白模"]
  B --> C["Blender 细化/UV/绑定"]
  C --> D["Aseprite/Substance 像素贴图"]

  F -->|"通过"| G["Addressables 打包"]
  F -->|"不通过"| C
  G --> H["场景组装/性能验收"]
```

### 9.2 工具职责

| 环节 | 工具 | 产出 |
|---|---|---|
| 白模/低模 | Blockbench / Blender | fbx + 剪影参考 |
| UV/绑定 | Blender | 33 骨骨架、权重 |
| 像素贴图 | Aseprite（主）/ Substance（辅） | png + 源文件 |
| 引擎集成 | Unity URP | prefab、材质、LOD |
| 资产管理 | Addressables | 分组、依赖、热更包 |

### 9.3 导入校验

| 项 | 阈值 | 失败处理 |
|---|---|---|
| 面数 | 角色 3–8k；武器 300–2,000；环境 1–5k | 退回 |
| 贴图 | 32 的倍数；角色密度 64–128px/m | 重做 |
| 色板 | ≤64 色/资产 | 合色 |
| 骨骼/插槽 | 33 骨白名单；挂点名合表 | 重绑定/修正 |
| 单位/轴心 | 1 unit = 1m；脚底 y=0 | 重置 |
| 材质 | ≤2/角色，≤1/环境 | 合并 |
| 描边 | shader 实现，不烘进贴图 | 改材质 |
| LOD/碰撞 | 角色/环境 ≥2 级；碰撞用简化 capsule/box | 补齐/重建 |
| 命名 | `CHR_/WPN_/ARM_/ENV_/VFX_/UI_` + `_v01` | 重命名 |

### 9.4 共享骨架与动画复用

全角色共用 33 骨骨架，新增骨骼须 Art/Tech 双签；动画按武器原型组织 8 套；防具/外观/皮肤不产生新动画；换装只替换网格与贴图，挂点与权重沿用。

### 9.5 命名与版本

`类型_子类_名称_变体_vNN`（例 `WPN_GS_flameguard_a_v03`）；每次交付版本 +1；弃用资产移入 `_deprecated`；Addressables 按「类型 + 场景」分组。

### 9.6 外包规范

| 项 | 要求 |
|---|---|
| 交付 | fbx（Y-up、1m）、png（无压缩）、.aseprite 源文件、引擎内截图 3 张 |
| 参考包 | 风格片 6 张、色板、三视角、剪影对比、不照搬清单 |
| 验收 | 2 轮迭代含在报价内；第 3 轮起计费 |
| 许可 | 原创声明；禁临摹竞品；AI 参与需书面声明 |
| 一致性 | 首批 3 件由 Art Lead 逐件验收后才放量 |
| 返工线 | 单件返工 >40% 暂停该外包方 |

### 9.7 AI 辅助边界

| 用途 | 允许 | 限制 |
|---|---|---|
| 概念/配色/剪影草稿 | 是 | 标注 AI；仅作情绪板 |
| 贴图材质底/噪声 | 是 | 必须重绘到 32–64 色板 |
| 最终角色/装备/UI 图标 | 否 | 人工重绘 + 风格评审 |
| 元数据 | 是 | 标 `ai_assist=true` |

## 12. Do / Don't 与风险

### 12.1 Do

1. 先画 65px 剪影，再画细节；剪影不过不建模。
2. 每套装备至少改 2 个剪影要素（§5.3）。
3. 光影/AO/高光画进贴图，不依赖实时光照。
4. 32 的倍数贴图、点采样、1px 屏幕描边。
5. 预警同时给颜色 + 形状 + 文字。
6. 遮挡用抖动淡出，保留描边与影子。
7. 先做 3 件量产试点，再定外包单价。
8. 交付即跑导入校验，不过不进 Addressables。
9. 参考登记来源；AI 参与标 `ai_assist`。
10. 风格测试通过前不接量产大单。

### 12.2 Don't

1. 不做 voxel 体素建模，不把方块造型当 voxel。
2. 不用全屏降分辨率/后处理像素化冒充像素风。
3. 不用 PBR 法线/粗糙度/金属度工作流。
4. 角色贴图密度不低于环境，否则糊进背景。
5. 不用纯黑纯白，不让阴影完全去饱和。
6. 不用半透明墙表示不可通行。
7. 不让武器与身体轮廓重叠到无法分辨。
8. 不复制竞品角色/UI/图标/配色，不描图。
9. 不为 UI 引入鼠标指针依赖（违反全键盘）。
10. 不为单个技能新建全身动画（走 additive）。

### 12.3 风险

| 风险 | 概率 | 影响 | 缓解 | 预警 |
|---|---|---|---|---|
| 剪影不清 | 高 | 高 | 三视图评审；8 原型对照 | T1 <70% |
| 「糊掉的 3D」 | 中 | 高 | 五要素自检；禁后处理像素化 | 关后处理明显掉档 |
| 成本超支 | 中 | 高 | 模块化、外包 35%、先试点 | 单套防具 >1.2 人月 |
| 高度/遮挡误判 | 中 | 高 | 四件套 + 边缘高亮 + 掩体不淡出 | QA 迷路/跳错 |
| 外包风格漂移 | 高 | 中 | 参考包 + 2 轮验收 + 导入校验 | 首轮返工 >40% |
| AI 版权/不一致 | 中 | 中 | 只做辅助、元数据标注、人工重绘 | 风格评审不过 |
| 贴图内存超 | 中 | 中 | 图集合并、共享材质、LOD | 1.0 >1.5GB |
| 色盲不可辨 | 中 | 中 | 形状+亮度冗余、3 套色板 | T3 色盲 <65% |
