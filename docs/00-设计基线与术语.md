# 设计基线与术语

> 本文件是 Project Hot 的**单一事实源**。所有 PRD/TDD/美术/ADR/任务数字以本文件为准；变更必须先走 ADR + Human 批准。
>
> 阅读顺序：`AGENTS.md` → 本文件 → 你的 `TASK-###` brief → 相关章节/ADR。

---

## 1. 一页纸

**一句话**：保留《热血英豪》的「装备 = 招式 + 全键盘 ZXCV 读招」，把视角改成 2.5D 斜俯视，用 3D 低多边形 + 像素贴图呈现，做成 PC 优先、服务器权威、公平付费的动作 MMO。

**产品形态**：
- 2.5D 俯视角、3D 低多边形 + 像素贴图。
- 全键盘 ZXCV；鼠标不参与战斗/镜头。
- 装备 = 招式包；武器原型 + 战斗核心 + 防具 + 符文 + 外观。
- 城镇大厅 + 野外频道 + 4/8 人副本 + 1v1/3v3/8 人竞技场。
- PC/Steam 优先；F2P + 外观/战令/创始人包；不卖属性。

**目标用户**：
1. 热血英豪 / 热斗传说 / Lost Saga 老玩家：怀念装备=招式、ZXCV 读招、房间制 PvP。
2. 2.5D 动作 MMO 玩家（Lost Ark / Ragnarok Online / Tree of Savior）：想要更深的操作与 Build。
3. 像素/低多边形美术爱好者（MapleStory / Hytale / Trove / 独立游戏）：想要有辨识度的 3D 像素世界。
4. 竞技动作玩家：1v1/3v3 排位、读招、连段、赛季。
5. 内容创作者/UGC 玩家：皮肤、招式组合、社区赛事。

**设计支柱**：
1. **装备即 Build**：一件核心改变打法，外观与强度分离；收集是为了表达，不是为了数值碾压。
2. **读招与连段**：ZXCV 易上手、难精通；防御/完美格挡/冲刺/击飞/受身构成通用猜拳。
3. **2.5D 可读性**：固定斜俯视、清晰预警、强剪影、高度/遮挡规则；不靠鼠标也能稳定操作。
4. **公平长线**：不卖属性；赛季、UGC、外观、社区赛事支撑长期运营。

**不做的方向**：
- 不做自由 3D 镜头/无缝开放大世界/自由飞行。
- 不做固定职业/传统战法牧。
- 不做 P2W、无保底强度抽奖、霸体类机制特权。
- 不做鼠标瞄准/鼠标镜头依赖。
- 不做写实 3A 美术。

## 2. 核心循环

```text
登录
  → 城镇（社交/交易/打造/接任务）
  → 野外/副本/竞技场（匹配或组队）
  → 战斗（读招/连段/掉落）
  → 经验/装备/材料/荣誉
  → 调整 Build（武器/核心/防具/符文）
  → 更高难 PvE / 排位 PvP / 赛季目标
  → 回到城镇（社交/交易/展示）
```

**单局节奏**：
- 副本：8–15 分钟；PvP：3–5 分钟/局；野外：10–30 分钟。
- 每次登录至少完成一次「战斗 → 有意义的掉落/进度 → Build 调整」。

## 3. 2.5D 相机与战斗基线

### 3.1 相机

| 项 | 值 |
|---|---|
| 视角 | 固定 pitch=50°、yaw=45°；45–55° 仅作风格测试范围 |
| 投影 | 正交（默认）；风格测试可对比低 FOV 透视 |
| 正交尺寸 | 7–9，默认 **8**；以角色**有效剪影高度 1.8m（含帽/武器）**为基准；M0 只在 7–9 校准（6 对应 104px，不满足 70–90） |
| 角色占屏高 | **70–90px 只对默认 size8/pitch50/1.0× 成立（78.1px）**；size9=69.4px、size7=89.3px；H_eff=1.8m |
| 缩放 | 0.8–1.2×；键盘 `+/-`；默认固定 1.0×；70–90px 不跨缩放保持 |
| 平移 | 有限平移/跟随；不自由旋转；默认不启用 camera lead |
| 旋转 | 不旋转 |
| 鼠标 | 不参与镜头 |
| 遮挡 | 屋顶/树冠/高墙淡出；角色轮廓/阴影保留 |
| 屏幕边缘 | 目标/队友/危险指示器；**14m 锁定目标可能在屏外，用边缘指示** |
| 锁定 | Z 软锁定最近敌人（120° 锥，14m）；Q/Tab 可选切换 |
| 14m 可读性 | **居中相机正前方不可见**；剪影验收只覆盖 6/10m；14m 只做边缘指示/方向 |
| 20/30m zoom | `S ≥ d·sin(pitch)`（脚点）/ `S ≥ (d·sin p + 1.8·cos p)·1080/1032`（全身）；p50 约 17/26，不写死 15/23 |

### 3.2 玩法平面与高度

- 移动/战斗在 X/Y 地面平面；8 方向。
- Z 轴只用于：
  - 跳跃/短滞空（V）。
  - 击飞/浮空状态（launcher）。
  - 高低差（台阶/桥/悬崖）的视觉与落点判定。
- 不做自由飞行、不做空中自由瞄准、不做无限空战。
- 高度用影子、缩放、高度条、命中特效表达；空中可追击 1–2 段。

### 3.3 战斗资源

| 资源 | 首版基准 | 作用 | 恢复 |
|---|---|---|---|
| HP | 500 | 生存 | 药水/治疗/复活 |
| MP | 100 | 特殊技/必杀（部分） | 时间/命中/装备 |
| 架势（Guard） | 300 | 防御消耗；归零破防 | 时间/完美格挡 |
| 必杀槽 | 100 | Z+X+C 必杀 | 造成/承受伤害、连段 |

> 锁定 14m；冲刺 i-frame 2–6f；完美格挡本地 100ms/在线 150ms（以命中为中心）；防御交互 cap 200ms、容差 0.5 tick；破防 1.2s；反击 0.4s；首版基准，M0 调参。

### 3.4 通用规则（设计目标）

- 防御：C+X；正面 120° 锥；背后攻击 +20% 伤害/破防。
- 完美格挡：本地 100ms/在线 150ms（以命中为中心；在线 cap 200ms、容差 0.5 tick）内按下 C+X；0 HP 伤害；可 X 反击。
- 冲刺：双击方向；短 i-frame 2–6f；Shift 可选替代。
- 跳跃：V；跃击/空中攻击；落地硬直。
- 投技/抓取：由战斗核心定义（Z+方向+C 等），不是通用键；不设全员通用抓取。
- 受身：倒地后按方向/防御减少硬直。
- 连段衰减：同一套连段伤害递减；防止无限连。
- PvP 归一化：装备数值压缩到 ±5%；核心机制保留；赛季调参；机制符文 PvP 限 1–2 条。

### 3.5 帧数据基线（60fps 帧；以剑原型为例）

| 招式 | 输入 | 前摇 | 判定 | 后摇 | 伤害 | 硬直 | MP | 取消窗口 |
|---|---|---|---|---|---|---|---|---|
| 轻击 1 | C | 8f | 3f | 12f | 30 | 14f | 0 | 后摇前 4f |
| 轻击 2 | C→C | 7f | 3f | 14f | 32 | 15f | 0 | 后摇前 4f |
| 轻击 3 | C→C→C | 10f | 4f | 20f | 45 | 22f | 0 | 后摇前 6f |
| 重击 | X | 18f | 5f | 24f | 80 | 28f | 0 | 后摇前 8f |
| 特殊 1 | Z+C | 14f | 4f | 20f | 70 | 24f | 20 | 命中后 6f |
| 特殊 2 | Z+X | 20f | 6f | 28f | 110 | 32f | 30 | 命中后 8f |
| 特殊 3 | Z+方向+C | 16f | 5f | 22f | 85 | 26f | 25 | 命中后 6f |
| 特殊 4 | Z+方向+X | 22f | 6f | 30f | 120 | 34f | 35 | 命中后 8f |
| 必杀 | Z+X+C | 30f | 8f | 36f | 220 | 40f | 0（槽） | 无 |
| 空中轻 | V+C | 6f | 3f | 10f | 25 | 12f | 0 | 落地前 |
| 空中重 | V+X | 12f | 4f | 16f | 55 | 20f | 0 | 落地前 |
| 冲刺攻击 | 双击方向+C/X | 8f | 4f | 18f | 50 | 20f | 0 | 命中后 4f |
| 防御 | C+X | 2f | 持续 | 6f | — | — | 0 | — |
| 完美格挡 | 本地 100ms/在线 150ms C+X | 1f | 6f | 8f | — | — | 0 | 反击 X |

> 数值是首版调参基线，不是最终平衡；由战斗原型验证。

### 3.6 伤害公式（首版）

```text
Damage = Base
       × (1 + Atk / 100)
       × (1 - Def / (Def + 300))
       × ComboScale
       × PosMod
       × ElementMod
       × PvPMod
```

- `ComboScale`：1.0 / 0.9 / 0.8 / 0.7 / 0.6 / 0.5（按连段段数递减，最低 0.5）。
- `PosMod`：正面 1.0；侧面 1.1；背面 1.2。
- `ElementMod`：克制 1.2；被克 0.8；无 1.0。
- `PvPMod`：0.75（首版）；装备归一化后再乘。
- 防御：格挡时 HP 伤害 ×0.2、架势伤害 ×1.0；未格挡命中按基础架势伤害；架势归零破防 1.2s。
- 完美格挡：HP 伤害 0；架势 +10；反击窗口 0.4s。

## 4. 全键盘操作基线

### 4.1 经典布局（默认）

| 输入 | 功能 | 说明 |
|---|---|---|
| 方向键 / WASD | 8 方向移动 | 屏幕相对；角色朝移动方向 |
| 双击方向 | 冲刺 | 短 i-frame；Shift 可选替代 |
| Z | 瞄准/软锁定/特殊技修饰 | 轻按面向最近敌人；按住 + X/C |
| X | 重击 | 击飞/破防/终结；完美防御后反击 |
| C | 轻击 | 连段起手；拾取用 F |
| V | 跳跃 | 跃击/短滞空；V+C / V+X 空中攻击 |
| C+X | 防御/格挡 | Space 可选替代；完美格挡本地 100ms/在线 150ms |
| Z+C / Z+X | 特殊技 1/2 | 核心定义；消耗 MP |
| Z+方向+C / Z+方向+X | 特殊技 3/4 | 4 个指令技中的后两个；消耗 MP |
| Z+X+C | 必杀 | 消耗必杀槽 |
| 双击方向+C/X | 冲刺攻击 | 突进/位移 |
| F | 交互/拾取 | 键盘-only |
| Q/Tab | 切换锁定目标（可选） | 无鼠标 |
| +/− | 缩放（可选） | 默认固定镜头 |
| 鼠标 | 不参与战斗/镜头 | UI 键盘可完成 |

### 4.2 现代布局（可选）

| 输入 | 功能 |
|---|---|
| Z | 轻击 |
| X | 重击 |
| C | 技能 1 / 投技 |
| X+C | 技能 2 |
| 方向+C | 技能 3 |
| 方向+X+C | 技能 4 |
| Z+X+C | 必杀 |
| Alt | 软锁定最近敌人（现代布局） | 与经典 Z 软锁定等价 |
| V | 跳跃 |
| Space | 防御 |
| Shift | 冲刺 |
| F | 交互 |
| Q/Tab | 切换目标 |
| +/- | 缩放 |
| 鼠标 | 不参与战斗/镜头 |

> 两套布局都支持键位重映射；C+X 同时按冲突需专项测试；Space/Shift 为可选替代，不改变“全键盘”原则。
>
> **4 个指令技映射**：特殊 1 = Z+C；特殊 2 = Z+X；特殊 3 = Z+方向+C；特殊 4 = Z+方向+X；必杀 = Z+X+C。现代布局：技能 1 = C、技能 2 = X+C、技能 3 = 方向+C、技能 4 = 方向+X+C、必杀 = Z+X+C；软锁定 = Alt，Q/Tab 切目标。
>
> **方向组合判定**：方向键在 C/X 前 **≤3f（50ms）** 内按下 → 方向版（特殊 3/4、现代技能 3/4）；方向键已按住 **>3f（移动中）** → 基础版（特殊 1/2、现代技能 1/2），避免移动误触。优先级：**Z+X+C 必杀 > C+X 防御（仅 Z 未按住时）> 新鲜方向组合 > 基础特殊 > 普通攻击**。C+X 两键需同时按住、闭区间 **±50ms（3f）**；Z 按住时 C+X 不判防御，避免抢判必杀。
>
> **低 rollover 键盘**：必杀支持同按 Z+X+C，也支持顺序输入 Z→X→C（≤250ms）；特殊 3/4 支持 Z→方向→C/X 顺序输入；自检覆盖方向+Z+C、方向+Z+X、方向+C、方向+X+C；失败时提示顺序输入/改键。

### 4.3 键盘可用性硬指标

- 战斗、镜头缩放、菜单、匹配、聊天、副本/PvP 全流程不需要鼠标。
- 支持 6KRO/全键无冲键盘；常见薄膜多数键区可 3 键同时按，但**不保证**；2KRO 档默认 Space 防御。
- 必杀 Z+X+C 支持顺序输入（≤250ms）；自检覆盖“方向+Z+X+C”，丢键时提示顺序输入/改键。
- 键位冲突可检测、可重映射、可恢复默认。
- 手柄 post-1.0 评估/接入；不改变键盘-first 设计，不阻塞 1.0。

## 5. 装备与 Build 基线

### 5.1 槽位

| 槽位 | 内容 | 影响 |
|---|---|---|
| 武器 | 8 种原型 | 基础攻击动画/范围/速度；决定 C/X 手感 |
| 战斗核心 | 12 种（1.0） | 4 个指令技 + 必杀 + 被动；装备=招式的核心 |
| 防具 ×3 | 头/身/腿 | 防御/HP/抗性/套装（2/3 件，不做 4 件套）；外观 |
| 符文 ×2 | 被动/词条 | 攻速/暴击/减耗/机制微调 |
| 外观 | 时装/皮肤 | 纯外观；可覆盖装备外观 |
| 角色外观（纸娃娃） | 基础身体 + 槽位 | 全角色共享基础身体/骨架/动作；头发/脸/头饰/上衣/下装/鞋/手套/披风/主副武器独立；外观与战斗核心解耦 |
| UGC 纹理 | 固定 UV 贴图 | 只替换贴图不改几何；1.0 调色/贴花，完整编辑器/市场 S2 |

> 纸娃娃/装备槽的强制约束：**统一基础身体 + 共享 skeleton + 共享动画 + 模块化外观件**；换装不新增动作，不生成“整套角色 + 整套动作”。详见 [ADR-013](decisions/ADR-013-modular-avatar-and-ugc-textures.md) 与 [docs/09](09-角色与模块化装备系统.md)。

### 5.2 武器原型（1.0：8 种）

剑、巨剑、长枪、双刀、拳套、弓、法杖、链刃。

> 攻击频率/轻击/重击冷却由 **武器 profile**（空手也有独立 profile）决定，不是全局常量；一次攻击动作只结算一次伤害，recovery 内的重复输入不得重复命中。详见 `docs/03` §5.3。

### 5.3 战斗核心（1.0：12 种）

示例：
- **雷鸣核心**：雷属性突进/落雷/感电；适合双刀/长枪。
- **霜狱核心**：冰墙/减速/冻结；适合法杖/巨剑。
- **影袭核心**：背刺/瞬步/分身；适合双刀/拳套。
- **守御核心**：格挡反击/护盾/嘲讽；适合巨剑/长枪。
- 其余 8 种在 PRD 展开（火/毒/风/召唤/陷阱/连射/抓投/支援）。

### 5.4 稀有度与强化

- 稀有度：普通/稀有/史诗/传说；传说给**独特机制**，不给纯数值碾压；PvP 中标准化/受限，机制符文 PvP 限 1–2 条。
- 强化：+0–+10；不破碎；材料来自 PvE；不卖强化材料。
- PvP：装备归一化；核心机制保留；赛季调参。
- 无数值洗练/随机词条赌博（首版）；避免 P2W 与军备竞赛。

### 5.5 示例 Build

**疾风双刀**
- 武器：双刀（高攻速/短距离）
- 核心：影袭（瞬步/背刺/分身）
- 防具：轻甲套（移速/闪避）
- 符文：攻速 + 冲刺冷却
- 打法：Z 锁定 → 冲刺绕背 → C 连段 → Z+C 瞬步取消 → 必杀收割
- 弱点：正面硬拼弱；怕防御/范围控制。

## 6. MMO 系统基线

### 6.1 城镇

- 1 个主城，3 个区：市场/打造、公会/社交、训练/排位。
- 50 人/频道；可切换频道；拍卖/银行/邮件/公会/训练场/外观店。
- 无战斗（或安全区）；展示/社交/交易为主。

### 6.2 野外

- 1.0：2 张野外地图；30 人/频道。
- 开放 PvE、世界 Boss、定时事件、采集/探索（轻量）。
- 频道切换；跨频道组队；Boss 共享/贡献度。

### 6.3 副本

- 1.0：4 个（2 普通 + 1 困难 + 1 八人 RAID）。
- 4 人副本 8–15 分钟；RAID 15–25 分钟；匹配/私人房间。
- 机制：预警、破防、集火、分工、复活次数。
- 掉落：装备/材料/外观/赛季货币；保底与周常。

### 6.4 PvP

- 1v1 排位、3v3 排位、8 人 FFA 休闲。
- 3 张地图；障碍/掩体/高低差；归一化数值。
- MMR/段位/赛季奖励；断线/投降/重连；观战/回放（后续）。
- 反作弊与挂机惩罚。

### 6.5 社交/经济

- 好友、队伍、公会、聊天、邮件、拍卖、导师、表情。
- 货币：金币、荣誉、RAID 代币、晶石（付费）。
- 拍卖税 5%；交易限制；防 RMT/防复制；双录账本。
- UGC：1.0 调色/贴花皮肤；S2 完整编辑器/市场/分成。

## 9. 商业化与 KPI

### 9.1 商业化

- F2P；创始人包 $24.99；战令 $9.99/季；外观 $4.99–19.99；栏位/便利付费。
- **价格提案（Human 批准后生效）**：创始人包 $24.99（外观/称号/30 天战令/1 栏位）；战令 $9.99/季；外观 $4.99/$9.99/$14.99/$19.99；栏位 $2.99；便利 $1.99–4.99。
- 不卖属性、不卖强化材料、不卖强度抽奖。
- UGC 市场 S2 起；创作者分成；审核/税务/法律评估。
- 三档情景（示意，不是预测）：
  - 5k CCU / 50k MAU / 3% 付费 / $25 ARPPU ≈ $37.5k/月
  - 20k CCU / 200k MAU / 4% 付费 / $30 ARPPU ≈ $240k/月
  - 50k CCU / 500k MAU / 5% 付费 / $35 ARPPU ≈ $875k/月

> 成本/盈亏平衡见 `docs/02` §11；中档 20k CCU 情景可能不足以覆盖总成本，需财务验证；不因此回到卖属性。

## 10. 执行模型与路线图

- **执行模型（Human 2026-10-17 确认）**：**1 名 Human Architect/Decision-maker（你）+ AI agent swarm + 按需外包/顾问**；技术侧 token 预算不设上限，不再以 12–18 FTE 作为技术成本/排期基线。
- AI agents 覆盖：工程、工具、测试、数据分析、文档、内容管线、部分美术/音频/本地化初稿；最终美术/法律/发行/客服仍需 Human/外包。
- 周期：技术工程可按 AI-native 压缩；**EA 12–15 个月、1.0 18–24 个月是内容/美术/合规/运营门禁估算，不是工程人力估算**。
- 里程碑：
  - M0（0–2 月）：战斗+联网原型；1 张图、2 核心、2 人；100ms/2% 丢包。
  - M1（2–5 月）：垂直切片；4 人副本、城镇、持久化、2k CCU 压测。
  - M2（5–9 月）：Alpha；8 人 PvP（3v3/8FFA）、2 副本、2 PvP 模式、匹配/反作弊。
  - M3（9–18 月）：Beta；内容完成、LiveOps、本地化、5k CCU。
  - M4（18–24 月）：上线；10k CCU、多区。
- 范围缩放：按 **AI agent 吞吐 + 外包产能 + 合规**调整；旧 5–10/12/25 人假设作废。内容跟不上就砍副本/外观/赛季，不砍核心联机/战斗。
- 风险：最终美术/音频/本地化/法律/发行/客服仍需 Human/外包；AI 产出需 review/QA，不把“token 无限”当成“质量自动达标”。

## 13. 假设与开放问题

### 已确认（Human）
- 2.5D 俯视角；全键盘 ZXCV；装备=招式；PC 优先；不卖属性；AI agent 为主执行。

### 假设（待验证）
- 执行模型：1 Human Architect + AI agents + 按需外包；技术 token 不设上限；不以 12–18 FTE 为技术基线。
- 18–24 个月到 1.0（内容/美术/合规/运营门禁估算，不是工程人力估算）。
- 全球 PC 先发，国服后置。
- Unity 6.3 + Fusion 2 + Nakama/Agones 可行。
- 30Hz + 预测 + 200ms 回放能满足 2.5D 近战手感。
- 外观/战令能覆盖服务器+AI/外包+运营成本；10k CCU 需验证；旧 12–18 FTE 成本模型作废。
- 2.5D 俯视 + 全键盘能保留英豪的读招深度。
- 美术预算 65–174 人月（±30%；分项 33–85/65–170，C6 87/174，合计取上限；AI 辅助可压缩，但按外包/人工验收计；M0 后重估）。
- 角色占屏 70–90px @1080p（约 6.5–8.3%；有效高度 1.8m、size 7–9、pitch 50°）；M0 校准。

### 待核实
- 竞品停运时间/地区差异/在线数据。
- Fusion 2 最新定价/房间上限。
- Unity 6.3 LTS 具体许可与 2026 定价。
- 目标地区版号/发行要求。
- 美术风格测试结果（3D low-poly vs 2D billboard）。

### 开放问题
- 最终产品名/品牌。
- 手柄 post-1.0 评估（默认不阻塞 1.0）。
- UGC 编辑器上线时间与审核方案。
- 国服发行商/版号策略。
- 电竞赛事/社区赛事投入。
- 是否引入 AI NPC/生成内容（另立专题）。
