# 2.5D 美术研究简报（供 C6 / TDD 使用）

> 工作材料，不是最终文档。最终输出：`docs/04-3D像素美术风格指南.md`。

## 1. 推荐路线

**3D 低多边形 + 像素贴图 + 固定 45–55° 正交斜俯视**；不是 voxel、不是 2D billboard、不是全屏像素化。

理由：
- 装备/朝向/动画/换装模块化；适合长线内容。
- 像素贴图保留冒险岛式辨识度；3D 空间/遮挡/高度可做。
- 管线成熟（Blockbench/Blender/Aseprite/Unity）；可外包；AI 可辅助概念/变体/占位。

## 2. 参考与做法

### Hytale（官方美术管线）
- 低多边形/方块+四边面；无 PBR；贴图内画光影/AO/高光；避免纯黑纯白；阴影带颜色。
- 角色/饰品 64px/单位；道具/方块 32px/单位；贴图 32 的倍数；拉伸 0.7–1.3×。
- 启示：3D 像素的关键是“贴图当插画”，不是 PBR。

### MapleStory
- 2.5–3 头身、强轮廓、大眼/表情、夸张武器、装备辨识、时装。
- 启示：斜俯视下也要保证帽子/肩甲/武器/披风剪影；装备是身份表达。

### GetAmped
- 停格动画（666 个动作）；头/眼/鼻/口/体/饰品模块；.skin 文件。
- 启示：8–12fps 阶梯动画 + 模块化 avatar 可行；UGC 是长期资产。

### Lost Ark / RO / Diablo / Hades（2.5D 俯视）
- 固定斜俯视；技能预警/地面圈；冲刺 i-frame；房间/副本节奏；高度/遮挡。
- 启示：俯视可读性靠预警/剪影/颜色语言，不靠写实细节。

### Trove（voxel 反例）
- 强 voxel 辨识，但装备/动画/剪影成本高；不适合冒险岛式比例与模块化装备。

## 3. 建议参数

| 项 | 建议 |
|---|---|
| 相机 | 45–55° 正交；正交尺寸 7–9；角色占屏 8–12%；键盘缩放 0.8–1.2× |
| 角色 | 2.5–3 头身；3–8k tris；30–40 骨骼；64–128px 贴图；32–64 色板 |
| 武器/装备 | 500–2k tris；64–128px；插槽/共享骨架；按武器原型复用动画 |
| 环境 | 2m 网格；模块 1–5k tris；128–256px；顶点色/烘焙光影 |
| 动画 | 8–12fps 阶梯；2–4 帧预备；命中停顿 50–100ms；屏震 |
| 描边/光照 | 轮廓 shader；ramp/flat lighting；无 PBR；阴影/边缘高亮 |
| 渲染 | 低分辨率 0.6–0.75 + 点采样；UI 高分辨率像素字体；不做全屏像素化 |
| VFX | 像素 sprite 64–128px；8–12 帧；预警圈/命中/落地/高度 |
| UI | 像素字体、9-slice、键盘提示、无鼠标光标、色盲 |

## 4. 斜俯视可读性规则

- 角色：帽子/肩甲/武器/披风/尾巴形成独特剪影；队友好/敌人坏用颜色语言。
- 高度：影子/缩放/高度条/落地特效；台阶/悬崖边缘高亮。
- 遮挡：屋顶/树冠/高墙淡出；角色轮廓/影子保留。
- 预警：地面圈/扇形/直线；颜色区分伤害类型；Boss 大招全屏提示。
- 距离：10/20/30m 可读性测试；不能只在大屏/近景好看。

## 5. 管线

Blockbench/Blender → Aseprite/Substance → Unity URP → 导入校验（面数/贴图/色板/骨骼/插槽）→ Addressables。
共享骨架；按武器原型复用动画；装备模块化；外包规范/验收。

## 6. 资产预算（首版估算，待 C6 细化）

- EA：1 角色基础 + 4 武器原型 + 6 核心 VFX + 10 防具套 + 15 敌人 + 2 Boss + 1 野外 + 1 城镇 + 2 副本 + 2 PvP 图。
- 1.0：8 武器 + 12 核心 + 20 防具 + 30 敌人 + 5 Boss + 2 野外 + 4 副本 + 3 PvP 图 + 1 城镇。
- 人月：角色/装备/敌人/Boss/环境/UI/VFX 分别估算；外包 30–50%。

## 7. 风格测试

1 角色 + 1 环境 + 3 装备 + 1 Boss；10/20/30m 可读性；对比 3D low-poly vs 2D billboard；通过后再量产。

## 8. 风险

- 斜俯视剪影不清/装备不可辨。
- 3D 像素“像糊掉的 3D”。
- 资产成本/外包一致性。
- 高度/遮挡误判。
- AI 生成资产版权/风格不一致。
