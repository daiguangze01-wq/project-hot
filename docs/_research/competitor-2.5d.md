# 2.5D 俯视角动作 MMO 竞品补充研究

> TASK-004 研究材料。最终以 `docs/01` 为准；在线人数为第三方 Steam 端数据，标「待核实」。

## 1. Lost Ark

- **相机/操作**：固定等距斜俯视、8 向移动；WASD/点击 + Space 翻滚（短位移、长无敌少）；技能 CD + 三脚架。
- **战斗**：副本考反制、虚弱条、多段预警；4 人守卫、8 人 RAID、3v3/1v1。
- **装备/Build**：Honing 装等 + 刻印/卡牌；装等即门票。
- **商业化**：F2P + 水晶/月卡/直升；强化/材料经济。
- **优点**：Boss 地板预警/读条/反制窗口是标杆；2.5D 俯视可做大。
- **风险/教训**：日常作业、装等墙、RAID gatekeeping、P2W 观感；Steam 峰值约 132 万→约 5 千（2026-10，第三方，待核实）。
- **启示**：学读招/预警/RAID，不学数值墙/日常/强化赌博。

## 2. Ragnarok Online

- **相机/操作**：2.5D 俯视；相机可 360° 旋转/缩放；点击/键盘移动；8 向精灵。
- **战斗/成长**：素质点 + 技能 + 卡片；公会/WoE 每周两次、20 城。
- **商业化**：F2P + VIP（经验/掉落 150%）+ 商城。
- **优点**：2002 年上线，靠卡片/公会/攻城沉淀 20 余年。
- **风险/教训**：鼠标移动、可转相机、卖效率与我们的全键盘/固定相机基线冲突。
- **启示**：学公会战/长线社交，不学可转相机/VIP。

## 3. Tree of Savior

- **相机/操作**：2.5D 固定斜俯视，键鼠；技能循环 + 走位。
- **Build/联机**：80+ 职业、Rank、Build 模拟器/排行；公会/GvG/宝石战。
- **商业化**：F2P + TP 卖成长材料。
- **优点**：Build 深度/美术亮眼。
- **风险/教训**：职业数量压垮平衡与内容，周常副本重复；Steam 峰值约 5.3 万→约 170（第三方，待核实）；Re:Build 重置。
- **启示**：深度靠装备组合，不靠 80+ 职业；12 核心比 80 职业可维护。

## 4. Diablo III/IV（只借动作层）

- **相机/战斗**：固定等距；D3 无通用冲刺，D4 Space Evade（5 秒 CD、1 充能、无无敌帧）；精英词缀 + 地板预警 + 高对比轮廓。
- **商业化/联机**：买断 + 资料片 + 外观/战令；4 人合作；赛季。
- **优点**：打击感/掉落/预警一流。
- **风险/教训**：D3 现金拍卖行 2014 关闭；D4 赛季重置不适 MMO。
- **启示**：学短 CD 位移/预警/掉落，不做拍卖行/强制赛季重置。

## 5. Hades（只借动作层）

- **相机/战斗**：固定斜俯视；Dash 带短暂无敌帧，默认 1 次、可升 2 次；攻击/特攻/施法 + 冲刺攻击。
- **Build/商业化**：Boon + 锤子 + 信物；单机买断。
- **优点**：i-frame 手感/短房间/起手清晰；清房→选奖励→下一房。
- **风险/教训**：单机不能直接 MMO 化。
- **启示**：把短冲刺 + 短房间做成副本最小单元。

## 6. GetAmped / Rumble Fighter

- **相机/操作**：3D 固定视角；方向键 + ZXCV（日服 R：Z 瞄准/X 强/C 弱/V 跳）；房间 2–8 人（后 16）。
- **装备/联机**：配件/卷轴决定招式，风格=职业；房间/锦标赛/公会战。
- **商业化**：F2P，GM/RM 双币，RM 道具更强。
- **优点**：装备=招式/读招/房间制可迁移；房主建局/观战/短局契合大厅。
- **风险/教训**：付费强度膨胀与停运重开。
- **启示**：招式全可解锁，付费只卖外观。

## 7. 2.5D 六条设计结论

- **固定相机**：所有关卡只为 45–55° 一个视角构图；高墙/树冠淡出/剖切；屏外攻击加边缘指示；绝不加鼠标转镜。
- **8 方向**：对角线归一化；技能判定吸附 8 向、命中框略宽；避免贴身空。
- **朝向/软锁定**：出手自动面向 45° 扇区最近目标，方向可覆盖；连招保持软锁，冲刺/受击断锁；脚下画朝向环。
- **高度/遮挡**：Z 只做跳跃/击飞/高低差；影子 + 地面圈 + 高度刻度；可跳 ≤1 个身位；按 Y 排序并让遮挡物透明。
- **Boss 预警**：地板色块 + 读条 + 音效三通道；红=即伤、黄=延迟、蓝=可反制；窗口 0.5–1.5 秒；多段机制给安全区。
- **PvP 地图**：对称 2–3 车道、有限高低差、无屏外 spawn、明确 choke；支持 3v3/8FFA 与观战。

## 8. 应吸收 / 应避免

**吸收**：
1. 固定相机 + 8 向是低成本、高可读性的主动选择，做成品牌。
2. 副本以「预警→反制/闪避→虚弱/击飞」为核心，演出学 Lost Ark。
3. 装备=招式给深度，但先做 8–12 套入门装备模板，共用冲刺/跳跃/防御/受击/浮空/抓取六种通用动词。
4. 大厅 + 频道 + 房间制 PvP 与 GetAmped/Rumble Fighter 同构，匹配成本低。
5. 定时公会 GvG（WoE 式）比日常任务更能造长线社交。
6. 付费只卖外观/战令/创始人包；招式与掉落全部可玩到。

**避免**：
7. 装等墙、日常作业、RAID gatekeeping。
8. 80+ 职业/无限 Build 的平衡债。
9. 卖强度、扭蛋配件、付费道具更强。
10. 屏外秒杀、鼠标镜头、强制赛季重置、现金拍卖行。
