# 竞品研究简报（供 C1 / PRD 使用）

> 状态：工作材料，不是最终文档。事实以来源为准；不确定项标「待核实」。
> 最终输出：`docs/01-竞品调研与机会分析.md`。

## 1. 核心结论

- 这类游戏的护城河不是“3D/像素”，而是 **装备=招式的内容管线** + **低门槛高上限的读招**。
- 同类死因高度重合：卖强度、内容断供、人口跌破匹配阈值、代理/分区断层、新手壁垒、外挂。
- 2.5D 俯视角动作 MMO 有成熟结构（Lost Ark/RO/Tree of Savior），但“装备=招式 + 全键盘 ZXCV + 像素”是空位。

## 2. 关键样本

### 热血英豪 GetAmped（CyberStep，2002 至今；国服盛大）
- 2.5D 侧视；方向键 + Z 瞄准、X 强攻、C 弱攻、V 跳；C+X 防御；Z+X/C 特殊；Z+X+C 必杀；双击方向冲刺；V+C/V+X 空中攻击。
- 一件装备 = 一套招式 + 必杀；外观与技能分离；周更武器/月更职业；皮肤编辑器支持头/眼/鼻/口/体/饰品模块与 666 个停格动作；.skin 文件。
- 后期「倒闭装」无保底抽奖、霸体、强化/徽章叠数值 → P2W、技巧被氪金碾压、老手壁垒、新增流失。
- 来源：Wazap 2007 操作表、国服装备说明、17173 回顾、GetAmped 皮肤编辑器官方页。

### 热斗传说 Rumble Fighter（Nimonix，2007；地区服多已关停）
- 3D 8 人房间；职业 + 圣卷 + 外核三层 Build；PvP 模式多；PvE 波次/Boss/僵尸/生存。
- 商城卖属性/独占连招；12 年三易代理（OGPlanet→GamesCampus→Redfox）；账号/社区迁移流失。
- 启示：层数越多，平衡/付费越难；账号连续性/单一大服重要。
- 来源：Jeuxvideo 2009 评测、MMOs.com 等（待核实具体停运时间）。

### GetAmped 2（2010–2020）
- 3D、最多 20 人；自定义皮肤；职业/装备；PvE Mega Force/Arcade；PvP Deathmatch/Dogfight/Tournament。
- 2020-06-04 停运；P2W、镜头不直观、操作门槛高。
- 来源：MMOs.com 评测。

### Lost Saga（IO Ent.，2009；韩服存续）
- 3D 横版；实时换英雄（1~0、-、=）；换人需装备齐全；不同英雄必杀可串连招；成长=英雄×四件装备×强化×宠物×时装。
- NA 2019-09-13 停运；英雄/装备双膨胀，新人组不出阵容。
- 启示：收集不能成为入场券；租用/统一数值的竞技模式。
- 来源：Steam 公告、官方指南。

### KurtzPel
- 3D 动漫动作；双 Karma 切换；PvE/PvP；手感成立，但 PvE 薄、内容断供、长期 EA、在线极低。
- 启示：动作 MMO 必须有持续 PvE/内容节奏，不能只做竞技场。

### Naraka: Bladepoint
- 3D 近战 BR；蓄力>普攻>振刀>蓄力；振刀缴械；60 人；一年破千万。
- 启示：一条易读的猜拳能撑起 3D 近战大众化；读招比复杂连段更重要。

### PSO2: NGS
- 大厅+任务柜台；4 人队并入 12 人多人区；定时紧急任务聚人；1200 万注册。
- 启示：大厅+副本+合流+定时活动，抗低人口。

### Vindictus
- 城镇→码头→4 人 RAID；疲劳 16%/次；强化至 +20 成功率 3%；靠 Season 续命。
- 启示：副本结构可借鉴；疲劳/强化赌博与“技巧”叙事冲突。

### MapleStory
- 2D 像素；强轮廓/装备辨识/时装；20 年 IP/内容/活动复利。
- 启示：美术/IP/长线参考，不是玩法参考。

### Hytale
- 低多边形+像素贴图；角色 64px/单位、道具 32px/单位；无 PBR；贴图内画光影；Blockbench 管线。
- 启示：3D 像素最可执行路线。

### GetAmped 皮肤编辑器
- 头/眼/鼻/口/体/饰品模块；666 个停格动作；10 种动画；.skin 文件。
- 启示：模块化 avatar + UGC 可做长期差异化，但需审核/商业化。

## 4. 横向矩阵维度

视角 / 操作 / 装备层数 / PvP 规模 / PvE / 联机结构 / 美术 / 商业模式 / 运营状态 / 核心教训。

## 5. 失败模式

1. P2W/无保底强度抽奖/霸体特权。
2. 内容断供/PvE 太薄。
3. 人口跌破匹配阈值/分区碎片化。
4. 频繁换代理/账号迁移。
5. 新手壁垒/老手内卷。
6. 外挂/经济崩。
7. 技术债/画面老化。

## 6. 机会定位

**2.5D 俯视 + 装备=招式 + 全键盘 ZXCV + 3D 像素 + 公平付费 + PvE/PvP 双循环 + UGC（后期）**。

## 7. 设计启示（20 条，待 C1 展开）

1. 装备=招式做成管线：共享骨架/招式表/数值曲线。
2. 周更小件、月更大件，但强度横向。
3. ZXCV 入门 + 受身/浮空/取消/资源派生。
4. 通用猜拳：蓄力/普攻/破防/闪避/格挡。
5. 新装备给形状，不给纯数值。
6. 大厅+房间+4→12 人合流+定时活动。
7. 外观/UGC 交易分成+赛季。
8. 不卖属性/不抽强度。
9. 不做无保底抽奖。
10. 不做霸体类机制特权。
11. 不做收集阵容入场券。
12. 单一大服/稳定内容节奏。
13. 新手训练场/指令表/租用 Build。
14. 低人口合流/跨区/机器人补位（PvE）。
15. 服务器权威/回放/经济审计。
16. 2.5D 相机/预警/高度可读性。
17. PvE 必须有持续内容，不能只做 PvP。
18. 商业化靠外观/战令/创始人包。
19. 美术强剪影/装备辨识/像素风。
20. 技术选型先验证手感/联网，再扩内容。
