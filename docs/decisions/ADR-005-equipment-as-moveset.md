# ADR-005 — 装备 = 招式，不做固定职业

- 状态：accepted
- 日期：2026-10-17
- 决策者：Human Owner + Orchestrator
- 关联 REQ：REQ-CBT-001
- 影响范围：战斗、掉落、平衡、商业化、内容管线

## 1. 背景

《热血英豪》的核心资产是「一件装备 = 一套招式 + 必杀」。固定职业会简化平衡，但会失去 Build 深度与内容管线优势。

## 2. 选项

| 选项 | 优点 | 缺点 | 风险 |
|---|---|---|---|
| A. 固定职业 | 易做、易平衡、易教学 | 失去装备=招式差异；内容管线慢 | 低但产品平庸 |
| B. 装备=招式（武器+核心） | 内容可扩展、Build 深、还原英豪 | 平衡面大、新手门槛高 | 中 |
| C. 职业+装备双层 | 兼顾 | 层数多、付费/平衡复杂 | 高 |

## 3. 决策

选择 **B：装备=招式**。

- 槽位：武器原型 + 战斗核心（4 技能 + 必杀 + 被动）+ 3 防具 + 2 符文 + 外观。
- 武器决定基础 C/X 手感；核心决定指令技/必杀。
- 不做固定职业；用「推荐 Build/训练场/租用」降低门槛。
- 强度横向：传说给机制，不给纯数值碾压；PvP 归一化。

## 4. 后果

### 正面
- 内容管线可模块化：新核心=新玩法，不需要新角色。
- 收集/外观/赛事/直播表达强。
- 与英豪老玩家预期一致。

### 负面/代价
- 平衡组合爆炸；需要数据驱动/模拟/赛季调参。
- 新手不知道怎么搭配；需要推荐 Build/试用。
- 美术要保证装备在斜俯视下可辨识。

### 跟进
- PRD 定义 8 武器/12 核心/20 防具的定位与平衡杠杆。
- TDD 数据驱动招式/帧数据/模拟测试。
- 1.0 前做「租用核心/训练场」降低门槛。

## 5. 复访触发

- 平衡失控/新手流失严重。
- 内容管线成本高于预期。
- Human 改向固定职业。

## 6. 来源

- 热血英豪装备/招式资料（`docs/01`）。
- Rumble Fighter 职业+圣卷+外核的教训（层数越多越难平衡）。
