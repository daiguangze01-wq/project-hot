# ADR-013 — 统一基础模型 + 模块化装备（纸娃娃）与可替换纹理

- 状态：accepted（Human 方向 2026-10-18；细节后续补）
- 日期：2026-10-18
- 决策者：Human Owner + Art/Tech
- 关联 REQ：REQ-VIS-002、REQ-ART-001/002、REQ-CBT-001（外观与装备解耦）
- 影响范围：角色、装备、动画、UGC、美术管线、网络同步、审核

## 1. 背景

早期 AI 生成把“整套角色 + 动作”当成一个资产，导致：

- 每套衣服/发型都要重新生成整套动作，无法复用；
- 玩家换装、玩家自绘纹理无法实现；
- 与 ADR-010 的“共享骨架、装备模块化”冲突。

参考作品：

- 冒险岛：角色由基础身体 + 头发/脸/衣服/披风/武器等层组合，动作共享。
- 热血英豪：官方头像编辑系统支持头发、脸部、身体、服装的 2D/3D 编辑与自定义造型上传。
- 热斗传说：自由造型系统支持上传自定义造型文件。
- 3D MMO/Unity 管线：共享 skeleton + 模块化 skinned mesh/骨骼挂点 + 材质槽/贴图 atlas，是标准做法。

## 2. 选项

| 选项 | 优点 | 缺点 | 风险 |
|---|---|---|---|
| A. 3D 低模统一基础身体 + 模块化装备（ADR-010） | 自由转向/遮挡/换装/共享动画；UGC 纹理可做 UV 模板；与现有 Unity 一致 | 需要基础 body + 装备 mesh/绑定；AI 不能直接产出可用的模块化 3D | 中 |
| B. 2D 分层纸娃娃（冒险岛/英豪式） | 像素味最直接；AI 生成单件头发/衣服较容易；用户画纹理直观 | 8 向 × 动作 × 层数资产爆炸；与 ADR-010 冲突；遮挡/排序复杂 | 中高 |
| C. 每套造型生成完整角色 + 完整动作 | 单套看起来完整 | 无法复用、无法换装、无法 UGC；成本爆炸 | 高（否决） |

## 3. 决策

选择 **A：3D 统一基础模型 + 模块化装备 + 固定 UV 的可替换纹理**。

- 所有角色共用 **同一基础身体 mesh + 同一 skeleton + 同一套动画**。
- 外观槽位：`hair / face / head_accessory / top / bottom / shoes / gloves / cape / weapon_main / weapon_offhand`。
- 每件装备是独立 mesh（skinned 或挂在骨骼 socket），共享材质/贴图槽；外观与战斗核心解耦（同一把剑可以有不同 skin）。
- 玩家自绘纹理只覆盖 **固定 UV 的装备/头发/衣服贴图**，不改变几何；上传前做尺寸/格式/内容校验，服务端存 hash/审核状态。
- 2D 分层纸娃娃只作为**风格样张**；若 Human 最终选 2D，需要新 ADR 取代 ADR-010，不在本 ADR 默认范围。
- AI 生成定位：概念/色板/贴图/花纹/UGC 模板；**不再生成“整套角色+整套动作”作为生产资产**。3D mesh 由人工/Blender 或 AI 3D + 清理完成。

## 4. 后果

### 正面
- 一套动画覆盖所有外观，内容产能从“每套角色”变成“每件装备”。
- 换装/染色/皮肤/UGC 可行；适合 F2P 外观付费。
- 与 ADR-010/005 一致：装备决定外观与招式，但两者可分离。

### 负面/代价
- 需要先定义基础身体比例、骨架、UV 模板、槽位挂点。
- 装备 mesh 要匹配骨架/遮挡；头发/披风需要骨骼/物理。
- UGC 需要审核、存储、带宽、版权/违规处理；不能直接信任客户端纹理。
- AI 不能一步生成可绑定 3D 装备；仍需 3D 建模/绑定。

### 跟进
- 新建 `docs/09-角色与模块化装备系统.md` 细化 slot/数据/动画/UGC。
- 生成 **基础身体 + 2 发型 + 2 上衣 + 1 武器 + 1 披风** 的模块化样张。
- 用 KayKit/CC0 占位验证共享动画 + 换装；再替换正式资产。
- 定义 UV 模板、贴图尺寸、色板、UGC 审核策略。

## 5. 复访触发

- 风格测试证明 3D 低模无法达到目标像素感。
- 模块化装备成本/遮挡不可接受。
- Human 决定改 2D 纸娃娃（需新 ADR 取代 ADR-010）。
- UGC 审核/合规成本超预期。
