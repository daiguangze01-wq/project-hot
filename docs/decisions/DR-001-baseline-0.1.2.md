## 1. 问题

REV-003 在 `docs/00`–`docs/07` 发现 7 条 blocker，其中多条涉及基线数字/口径。起草期已按推荐值修正，但按 `docs/00` §15 与 AGENTS.md §9，基线变更需要 Human 批准。本 DR 记录变更前后值，供 Human 一次性批准/修改。

## 4. 建议

- `docs/00` version 0.1.2 冻结；
- 必要时转 ADR-013；
- 关闭 REV-003 B-1/B-3/B-4/B-5/B-6/B-7；
- 更新 docs/07、backlog、run log。
