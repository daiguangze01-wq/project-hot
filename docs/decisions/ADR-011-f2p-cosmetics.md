# ADR-011 — 商业化采用 F2P + 外观/战令/创始人包，不卖属性

- 状态：accepted
- 日期：2026-10-17
- 决策者：Human Owner + Orchestrator
- 关联 REQ：REQ-BIZ-001/002
- 影响范围：商城、经济、平衡、口碑、收入

## 1. 背景

热血英豪/GetAmped 2/Rumble Fighter 的衰落都与 P2W/无保底强度抽奖/属性装备有关。本项目要公平竞技+长线，但需要收入覆盖服务器/团队。

## 2. 选项

| 模式 | 优点 | 缺点 | 风险 |
|---|---|---|---|
| A. F2P + 外观/战令/创始人包 | 人口大、公平、口碑好 | 收入依赖规模/外观质量 | 中 |
| B. B2P + 外观 | 门槛/作弊少、收入确定 | 人口少、匹配慢 | 中 |
| C. F2P + 卖属性/强度抽奖 | 短期收入高 | P2W、流失、口碑崩 | 高 |
| D. 订阅 | 稳定收入 | PC 动作 MMO 接受度低 | 中高 |

## 3. 决策

选择 **A：F2P + 外观/战令/创始人包**。

- 创始人包 $24.99；战令 $9.99/季；外观 $4.99–19.99；栏位/便利付费。
- 不卖属性、不卖强化材料、不卖强度抽奖；不做「倒闭装」。
- PvP 归一化；传说装备给机制不给纯数值。
- UGC 市场 S2 起；创作者分成；审核/税务/法律评估。
- 三档收入情景仅作测算，不承诺。

## 4. 后果

### 正面
- 公平口碑/竞技生态/长线信任；与英豪老玩家的痛点对齐。
- 外观/UGC/战令可长期扩展；不破坏平衡。
- 适合 Steam/全球/社区赛事。

### 负面/代价
- 收入依赖 DAU/外观质量；小规模可能覆盖不了成本。
- 需要强 LiveOps/外观产能/社区运营。
- 不能靠“卖强度”快速回本。

### 跟进
- PRD 做三档敏感性分析/成本模型。
- LiveOps 10 周赛季；外观产能管线。
- 若收入不足，优先加创始人包/外观/便利，不卖属性。

## 5. 复访触发

- 收入无法覆盖服务器/团队。
- Human 改向 B2P/订阅。
- 外观产能/审美不达标。
