# ADR-012 — PC/Steam 优先，全球先发、国服后置

- 状态：accepted
- 日期：2026-10-17
- 决策者：Human Owner + Orchestrator
- 关联 REQ：REQ-MMO-001 / REQ-BIZ-002
- 影响范围：平台、区域、发行、合规、服务器

## 1. 背景

全键盘 ZXCV、2.5D 动作 MMO、核心用户是 PC 老玩家；国服需要版号/代理；全球 Steam 可以先验证。

## 2. 选项

| 选项 | 优点 | 缺点 | 风险 |
|---|---|---|---|
| A. PC/Steam 全球先发 | 用户匹配、发行简单、验证快 | 国服延迟；本地化/支付 | 中 |
| B. 国服先发 | 核心怀旧用户 | 版号/代理/合规周期长 | 高 |
| C. 主机先发 | 手柄/客厅 | 键盘核心不匹配；认证复杂 | 高 |
| D. 移动先发 | 人口大 | 操作不匹配；性能/触屏 | 高 |

## 3. 决策

选择 **A：PC/Steam 优先，全球先发（NA/EU/SEA），国服后置**。

- 键鼠/全键盘；1.0 键盘-first、不强制手柄；手柄 post-1.0 评估；主机后续评估。
- 首发语言：EN/CN（简中）；后续 JP/KR/其他。
- 国服：找发行商/版号；独立服务器/合规；不阻塞全球。
- 服务器区域：NA/EU/SEA；后续扩展。

## 4. 后果

### 正面
- 先验证玩法/美术/商业化；发行/合规压力小。
- 与核心用户/Steam 生态匹配；社区/愿望单可积累。
- 国服风险后置，不拖累首版。

### 负面/代价
- 国服玩家延迟/支付/社区分离；需要后续投入。
- 全球本地化/客服/支付/税务复杂。
- 主机/移动机会后置。

### 跟进
- PRD/TDD 定义区域/服务器/本地化/支付。
- 评估国服发行商/版号时间线。
- Steam 页面/愿望单/Playtest 计划。

## 5. 复访触发

- 国服发行商/版号提前落地。
- 主机/移动平台机会/合作。
- 全球发行/合规变化。
