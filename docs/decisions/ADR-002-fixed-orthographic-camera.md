# ADR-002 — 固定 45–55° 正交相机，键盘缩放/平移、不旋转

- 状态：accepted
- 日期：2026-10-17
- 决策者：Human Owner + Orchestrator
- 关联 REQ：REQ-VIS-001 / REQ-CTL-001
- 影响范围：相机、输入、关卡、美术、UI

## 1. 背景

2.5D 俯视需要确定相机是否旋转、是否透视、是否鼠标控制。项目要求全键盘、无鼠标，且像素风需要稳定像素密度。

## 2. 选项

| 选项 | 优点 | 缺点 | 风险 |
|---|---|---|---|
| A. 固定正交 45–55° | 像素密度稳定、可读性高、美术成本低、键盘友好 | 纵深弱、场景构图受限 | 低 |
| B. 固定低 FOV 透视 | 纵深感更好 | 像素密度不稳定、远处细节糊 | 中 |
| C. 可自由旋转 | 视角自由 | 美术/遮挡/可读性成本高；与全键盘冲突 | 高 |
| D. 鼠标控制相机 | 灵活 | 违背全键盘约束 | 高 |

## 3. 决策

选择 **A：固定正交 45–55° 斜俯视**。

- 支持键盘 `+/-` 缩放（0.8–1.2×）与有限平移/跟随。
- 不旋转、不跟随鼠标、不做相机碰撞。
- 若风格测试证明纵深不足，可在 ADR 中改为低 FOV 透视；当前默认正交。

## 4. 后果

### 正面
- 角色/装备在屏幕上大小稳定；像素贴图不糊。
- 关卡/遮挡/预警可按固定角度设计；美术可复用。
- 全键盘导航自然；无鼠标依赖。

### 负面/代价
- 场景构图变化少；高低差/背面空间需要阴影/缩放/边缘高亮补偿。
- 某些技能演出需要按固定镜头重新设计。

### 跟进
- 风格测试对比正交 vs 低 FOV 透视。
- 建立遮挡淡出/屋顶透明规则。

## 5. 复访触发

- 10/20/30m 可读性测试失败。
- 玩家反馈“太扁平/看不清高度”。
- 关卡设计需要更强纵深。
