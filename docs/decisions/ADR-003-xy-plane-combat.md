# ADR-003 — X/Y 平面战斗，Z 轴仅跳跃/击飞/高低差

- 状态：accepted
- 日期：2026-10-17
- 决策者：Human Owner + Orchestrator
- 关联 REQ：REQ-VIS-003 / REQ-CBT-002
- 影响范围：战斗、判定、关卡、联网、动画

## 1. 背景

2.5D 俯视下，如果保留全 3D 自由移动/空战，会带来镜头、判定、动画、联网复杂度。项目需要保留英豪的跳跃/击飞/连段，但不做自由飞行。

## 2. 选项

| 选项 | 优点 | 缺点 | 风险 |
|---|---|---|---|
| A. 全 3D 自由移动/空战 | 空间感最强 | 判定/镜头/动画/联网成本高；俯视难读 | 高 |
| B. X/Y 平面 + 高度状态 | 保留跳跃/击飞/连段；判定简单；俯视可读 | 空战深度受限 | 中 |
| C. 纯 2D 平面无高度 | 最简单 | 失去英豪的跳跃/空战特色 | 低但产品损失大 |

## 3. 决策

选择 **B：X/Y 地面平面战斗 + 高度状态**。

- 地面 8 方向移动；跳跃/击飞/浮空是状态，不是自由飞行。
- Z 轴用于：跳跃高度、击飞/浮空、台阶/桥/悬崖落点。
- 空中可追击 1–2 段；不做无限空战、不做空中自由瞄准。

## 4. 后果

### 正面
- 判定用地面 capsule/cylinder + 高度状态，联网简单。
- 俯视可读；美术/动画可复用。
- 保留英豪的跳跃/击飞/连段核心。

### 负面/代价
- 空战深度/观赏性弱于真 3D；需要用击飞/浮空/地形补偿。
- 高度表达依赖影子/缩放/特效，需专门规范。

### 跟进
- M0 原型验证跳跃/击飞/浮空手感。
- 美术定义高度/阴影/落地特效规则。

## 5. 复访触发

- 空战/高度不可读或玩家不买账。
- 竞品验证需要更强纵深。
- 联网/判定成本可接受且有更强需求。
