# ADR-010 — 美术采用 3D 低多边形 + 像素贴图，不做 voxel/2D billboard

- 状态：accepted
- 日期：2026-10-17
- 决策者：Art Lead + Human
- 关联 REQ：REQ-VIS-002 / REQ-ART-001/002
- 影响范围：角色、装备、动画、环境、管线、预算

## 1. 背景

需要 2.5D 俯视、像素风、装备模块化、可读性、AI agent 可参与生产。参考冒险岛的像素辨识度，但必须是 3D 资产。

## 2. 选项

| 路线 | 优点 | 缺点 | 风险 |
|---|---|---|---|
| A. 3D 低多边形 + 像素贴图 | 模块化/朝向/动画友好；像素辨识度；管线成熟 | 需要 shader/贴图规范；不是纯像素 | 中 |
| B. Voxel | 强 3D 像素辨识 | 装备/动画成本高；剪影块状；难做冒险岛比例 | 中高 |
| C. 2D billboard sprites | 纯像素、便宜 | 旋转/遮挡/装备模块化差；8 方向动画贵 | 中高 |
| D. 3D 正常渲染 + 全屏像素化 | 便宜 | 像“糊掉的 3D”，不是手工像素；可读性差 | 高 |

## 3. 决策

选择 **A：3D 低多边形 + 像素贴图**。

- 固定 45–55° 正交斜俯视；8–12fps 阶梯动画；64–128px 角色贴图；32–64 色板；描边/ramp 光照。
- 共享骨架；按武器原型复用动画；装备模块化。
- 2D billboard 作为风格测试备选；voxel 不作为默认。
- 不全屏像素化；用点采样/低分辨率渲染/像素 VFX/UI 保持像素感。

## 4. 后果

### 正面
- 装备/朝向/动画/换装容易；适合长线内容。
- 3D 空间/遮挡/高度可做；像素贴图保留辨识度。
- 管线（Blockbench/Blender/Aseprite/Unity）成熟；可外包。

### 负面/代价
- 不是“纯像素”，需要 Art Lead 把控风格。
- 斜俯视剪影/贴图密度/遮挡需要专门规范。
- 角色/装备资产成本仍高；需要模块化/复用。

### 跟进
- 风格测试：1 角色+1 环境+3 装备+1 Boss；对比 2D billboard。
- 建立贴图/色板/描边/导入校验。
- 资产预算/外包规范。

## 5. 复访触发

- 风格测试不通过/可读性差。
- 资产成本超预算。
- 团队/外包更擅长 2D 像素。
- Human 改向 voxel/2D。

## 6. 来源

- Hytale 美术管线（低多边形+像素贴图；角色 64px/单位、道具 32px/单位；无 PBR）。
- MapleStory 的像素辨识/装备设计。
- GetAmped 的停格动画/模块化 avatar。
