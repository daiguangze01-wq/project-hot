# ADR-014 — 2D 纸娃娃样张（仅风格验证，尚未取代 3D 基线）

- 状态：accepted（Human 方向 2026-10-20；范围仅限样张）
- 日期：2026-10-20
- 决策者：Human Owner
- 关联 REQ：REQ-VIS-002、REQ-ART-003/004
- 影响范围：角色表现、动画、装备装配、UGC、美术资产

## 1. 背景

- PixelLab API 已可用，2D 像素资产生成速度快。
- 参考冒险岛/热血英豪/热斗传说，用户希望验证“统一基础身体 + 头发/衣服/武器分层”的纸娃娃观感。
- 现有 ADR-010 的正式基线仍是 **3D 低模 + 像素贴图**；2D billboard 只能作为风格测试是 ADR-010 允许的备选。
- 因此本 ADR 只授权 **独立 2D 纸娃娃样张**，不等于放弃 3D 生产基线。

## 2. 选项

| 选项 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| A. 直接全面切 2D | 最快接近像素纸娃娃 | 资产量/方向/遮挡/UGC 不确定；推翻 ADR-010 | 暂不 |
| B. 先做独立 2D 样张，与 3D 对比 | 低风险；AI 可快速出层；保留回退 | 需要临时 2D 渲染/装配代码 | **采用** |
| C. 继续 3D 模块化 | 现有 U0 可复用 | 3D 模块化资产/绑定慢；AI 只能出概念 | 保留为对照 |

## 3. 决策

做 **1 个角色的 2D 纸娃娃样张**，放在独立场景/独立渲染路径，不替换当前 U0 主场景：

- 1 个基础身体 + hair_01 + top_01 + sword_01；
- 先 4 向（S/E/N/W），idle + walk；通过后再扩 run/attack；
- 层级：base body → bottom → top → hair → weapon；
- 同一 canvas/pivot/帧号；SpriteRenderer 排序；
- 样张通过 Human/可读性评审后，才考虑新 ADR 取代 ADR-010。

## 4. 后果

### 正面
- 能快速对比“冒险岛/英豪式纸娃娃”和“3D 低模+像素贴图”的观感。
- 现有相机/输入/移动/Hot.Sim/HUD 逻辑可复用。
- AI 2D 资产生成路径已跑通（PixelLab）。

### 负面影响/代价
- 角色渲染/动画/装备装配需要一套 2D 实现；不能直接复用 KayKit Animator/3D 装备。
- 4 向 × 动作 × 层的资产量；层对齐/遮挡/武器挂点要手工处理。
- UGC 纹理在 2D 层上的语义与 3D 固定 UV 不同，需要重新定义（每层贴图/调色板/模板）。
- 若最终选 2D，需新 ADR 取代 ADR-010，并更新 docs/00/02/03/04/07/08/09。

### 跟进
- 样张资产：PixelLab 生成 + Aseprite/脚本清理；hair 必须去掉脸/头残留。
- 2D 装配：`PaperdollAvatar`/层级排序/每层 Animator 或帧驱动。
- 样张评估：78px 身高、6/10m 可读、换装、武器跟随、UGC 测试。
- 决策门：通过 → 新 ADR 切 2D；不通过 → 回 3D 模块化（ADR-013）。

## 5. 复访触发

- 样张完成/评审；
- 2D 层资产成本超预期；
- 2D 无法满足 8 向/遮挡/换装；
- Human 最终选择 2D 或 3D。
