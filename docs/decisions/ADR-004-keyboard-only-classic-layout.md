# ADR-004 — 全键盘经典英豪布局；鼠标不参与战斗/镜头

- 状态：accepted
- 日期：2026-10-17
- 决策者：Human Owner + Orchestrator
- 关联 REQ：REQ-CTL-001–004
- 影响范围：输入、UI、相机、战斗、QA、无障碍

## 1. 背景

Human 明确：按照《热血英豪》的操作，不需要鼠标。项目需要保留 ZXCV 肌肉记忆，同时适配 2.5D 俯视。

## 2. 选项

| 选项 | 优点 | 缺点 | 风险 |
|---|---|---|---|
| A. 鼠标镜头/瞄准 + 键盘 | 现代、灵活 | 违背需求；增加依赖/门槛 | 高 |
| B. 全键盘经典英豪布局 | 还原、键盘-first、老玩家零学习 | C+X 同时按/键盘冲突；新玩家需教学 | 中 |
| C. 全键盘现代布局（Z 轻/X 重/C 技能/Space 防御/Shift 冲刺） | 新玩家友好 | 偏离英豪原版 | 低 |
| D. 手柄优先 | 动作游戏友好 | PC/键盘用户不买账；开发复杂 | 中 |

## 3. 决策

选择 **B 为默认 + C 为可选**：

- 默认经典布局：Z 瞄准/软锁定、X 重击、C 轻击、V 跳、C+X 防御、Z+X/C 特殊、Z+X+C 必杀、双击方向冲刺、F 交互。
- 现代布局可选；两套都全键盘、无鼠标。
- 鼠标不参与战斗/镜头；UI 键盘可完成；鼠标仅可选便利。
- 键位可重映射；Space/Shift 作为 C+X/冲刺替代；C+X 冲突专项测试。

**2026-10-18 复访（DR-002 批准）**：

- C+X 窗口统一 **±50ms（3f，闭区间，两键同按）**；**仅 Z 未按住时判防御**；Z 按住时 **Z+X+C 必杀优先**，避免经典布局必杀被防御抢判。
- 2KRO/薄膜档默认 **Space 防御** + 顺序输入/改键提示；NKRO/6KRO 仍支持原布局。
- 顺序必杀干净条件：`Z↓→X↓→C↓`、C−Z≤250ms、C−X≤50ms（距 X 按下）且不触发防御抢判；引擎需意图缓冲/取消。
- 真实键盘 3 款×100 次 ≥99% 仍待人工 QA（B6）；模型只验证键数/解析器。
- 依据：`validation/input/REPORT.md`、`validation/review/REVIEW.md` B4/M3/M4/B6、`docs/decisions/DR-002-validation-baseline-fixes.md`。

## 4. 后果

### 正面
- 最大程度还原英豪操作；老玩家迁移成本低。
- 无鼠标依赖；适合 PC/手柄/未来主机。
- 输入简单（8 方向 + 按钮），联网/回放更容易。

### 负面/代价
- C+X 同时按对键盘 rollover 有要求；需要测试/替代键。
- 远程/瞄准类技能需要软锁定/自动朝向；自由度低于鼠标。
- 新玩家需要教学/训练场。

### 跟进
- TDD 输入系统定义键位重映射/冲突检测/rollback。
- QA 做多键盘 rollover 测试；全键盘全流程验收。
- 训练场内置指令表/MP/取消窗口。

## 5. 复访触发

- 键盘冲突无法解决/大量玩家反馈按不出。
- Human 改向鼠标/手柄优先。
- 远程/瞄准玩法证明键盘不够。
