# 3D 像素美术风格指南

> 目标：在 2.5D 固定斜俯视下，用 3D 低多边形 + 像素贴图做出“像冒险岛一样有辨识度、但能自由换装/动作”的像素世界。
>
> 一句话：**不是 voxel，不是 2D billboard，不是全屏像素化；是“低多边形 + 手绘像素贴图 + 斜俯视剪影 + 阶梯动画”。**

---

## 0. 结论摘要

- **路线**：3D 低多边形 + 像素贴图；固定 45–55° 正交斜俯视；角色 2.5–3 头身、3–8k tris、64–128px 贴图、32–64 色板、8–12fps 阶梯动画。
- **可读性**：斜俯视剪影（帽子/肩甲/武器/披风/尾巴）、高度/阴影、遮挡淡出、预警颜色语言。
- **管线**：Blockbench/Blender → Aseprite/Substance → Unity URP → 导入校验 → Addressables；共享骨架/按武器原型复用动画。
- **先验证**：1 角色 + 1 环境 + 3 装备 + 1 Boss；6/10/14m 战斗可读性 + 20/30m 战术；3D low-poly vs 2D billboard 对比；通过后再量产。
- **最大风险**：斜俯视下装备/角色看不清；“像糊掉的 3D”；资产成本/外包一致性。

---

## 1. 风格定义与支柱

### 1.1 定义

| 项 | 定义 |
|---|---|
| 视角 | 2.5D 固定 45–55° 正交斜俯视 |
| 资产 | 3D 低多边形 + 手绘像素贴图 |
| 角色 | 2.5–3 头身；大眼/表情；夸张武器；强剪影 |
| 动画 | 8–12fps 阶梯；2–4 帧预备；命中停顿 |
| 光照 | flat/ramp；贴图内画光影/AO；无 PBR |
| 色彩 | 温暖、鲜明、有限色板；阴影带颜色；避免纯黑纯白 |
| UI | 像素字体/9-slice；高分辨率可读性；键盘提示 |
| 气质 | 热血、幽默、可爱但有力量；不是写实/暗黑 |

### 1.2 支柱

1. **一眼认出**：角色/装备/敌人靠剪影和颜色区分，不靠细节。
2. **装备是身份**：换核心/防具/外观能明显改变轮廓/特效。
3. **俯视可读**：6/10/14m 战斗内看清攻击/预警/队友/危险；20/30m 只作战术轮廓。
4. **手工像素感**：贴图当插画；不是 PBR/全屏像素化。
5. **可量产**：共享骨架/模块化/按武器原型复用；外包可控。

## 2. 参考拆解

### 2.1 MapleStory（2D 像素）

- 2.5–3 头身、大眼/表情、夸张武器、强轮廓、装备辨识、时装。
- 启示：像素风的核心是轮廓/配色/装备设计，不是分辨率；斜俯视也要保留这些。

### 2.2 Hytale（3D 低多边形+像素贴图）

- 低多边形/方块+四边面；无 PBR；贴图内画光影/AO/高光；避免纯黑纯白；阴影带颜色。
- 角色/饰品 64px/单位；道具/方块 32px/单位；贴图 32 的倍数；拉伸 0.7–1.3×。
- 启示：3D 像素的关键是“贴图当插画”，不是 PBR；Blockbench 管线可复制。

### 2.3 GetAmped（停格动画/模块化 avatar）

- 头/眼/鼻/口/体/饰品模块；666 个停格动作；.skin 文件。
- 启示：8–12fps 阶梯 + 模块化 avatar 可行；UGC 是长期资产。

### 2.4 Lost Ark / RO / Tree of Savior（2.5D 俯视）

- 固定斜俯视；8 方向；技能预警/地面圈；高度/遮挡；社交/副本。
- 启示：俯视可读性靠预警/剪影/颜色语言；不是靠写实细节。

### 2.5 Diablo III/IV / Hades（俯视动作）

- 俯视动作；冲刺 i-frame；技能预警；命中反馈；房间节奏。
- 启示：俯视战斗的“看清/躲开/打中”比“好看”更重要。

### 2.6 Trove（voxel 反例）

- voxel 辨识强，但装备/动画/剪影成本高；难做冒险岛比例/模块化装备。
- 启示：不作为默认路线；可作为特殊皮肤/活动。

## 3. 路线对比

| 路线 | 优点 | 缺点 | 适用 |
|---|---|---|---|
| **A. 3D low-poly + pixel texture（推荐）** | 模块化/朝向/动画/换装；像素辨识；管线成熟 | 需要 shader/贴图规范；不是纯像素 | 默认 |
| B. Voxel | 强 3D 像素辨识；UGC 友好 | 装备/动画/剪影成本高；比例受限 | 特殊皮肤/活动 |
| C. 2D billboard sprites | 纯像素；便宜 | 旋转/遮挡/装备模块化差；8 方向动画贵 | 风格测试备选 |
| D. 3D 正常渲染 + 全屏像素化 | 便宜 | 像“糊掉的 3D”；可读性差 | 不推荐 |

## 4. 相机与构图

| 项 | 值 |
|---|---|
| 视角 | 固定 45–55° 斜俯视 |
| 投影 | 正交（默认）；低 FOV 透视作为测试备选 |
| 正交尺寸 | 7–9（M0 可校准到 6–8） |
| 角色占屏高 | 70–90px @1080p（约 6.5–8.3%；有效高度 1.8m、size 7–9、pitch 50°；M0 校准） |
| 缩放 | 0.8–1.2×；键盘 +/- |
| 平移 | 有限跟随；不旋转 |
| 遮挡 | 屋顶/树冠/高墙淡出；角色轮廓/影子保留 |
| 高度 | 影子/缩放/高度条/落点预览 |
| 边缘 | 目标/队友/危险指示器 |
| UI | 键盘提示；不依赖鼠标光标（可选显示） |

**占屏口径**：屏高比 ≈ H × cos(50°) / (2 × orthoSize)；H=1.8m（含帽子/武器有效高度）、S=7–9 → 6.4–8.3%（69–90px @1080p），取整 70–90px。M0 用同一公式校准；不再使用 8–12% 旧口径。若需改相机/尺寸，走 ADR-002 复访。

**构图规则**：
- 战斗区域留出预警/走位空间；不要把角色塞在屏幕边缘。
- 高低差用阴影/边缘高亮/落点预览；不要靠贴图细节。
- 大型 Boss 允许占屏更大，但攻击预警必须可见。

## 5. 角色与装备

### 5.1 角色规格

| 项 | 建议 |
|---|---|
| 头身 | 2.5–3 头身 |
| 身高 | 1.4–1.6m（游戏单位） |
| 面数 | 3–8k tris（不含武器/披风） |
| 骨骼 | 30–40 |
| 贴图 | 64–128px；点采样；32–64 色板 |
| 材质 | 无 PBR；flat/ramp；贴图内画光影 |
| 动画 | 8–12fps 阶梯；2–4 帧预备；命中停顿 50–100ms |
| 插槽 | 头/肩/背/武器/披风/尾巴；模块化 |

### 5.2 斜俯视剪影

从上方看仍要能区分：

- **帽子/头盔**：形状/颜色/角/羽毛。
- **肩甲**：宽/尖/圆/不对称。
- **武器**：长度/弧度/发光/拖尾；举在身侧或背后。
- **披风/尾巴**：飘动方向/颜色；不要遮住脚。
- **轮廓**：角色外轮廓不要被环境同色吞掉；必要时描边/rim light。

### 5.3 装备/稀有度

- 武器 8 原型：剑/巨剑/长枪/双刀/拳套/弓/法杖/链刃；每种有独特剪影/动画。
- 核心 12：用 VFX/颜色/姿态区分（雷/冰/影/守御等）。
- 防具 20 套：轻/中/重；2/3 件套（不做 4 件）；套装轮廓明显；外观可覆盖。
- 稀有度：普通/稀有/史诗/传说；传说用独特 VFX/轮廓，不用纯数值。
- 外观：时装/皮肤可覆盖装备外观；不影响判定。

### 5.4 动画

- 8–12fps 阶梯；关键帧明确；2–4 帧预备；命中停顿 50–100ms。
- 共享骨架；按武器原型复用；核心只加 VFX/姿态。
- 攻击动作要有清晰的前摇/命中/后摇；不要用太多模糊/拖影遮住判定。
- 受击/击飞/倒地/起身要有强剪影；高度用影子/缩放。

## 6. 环境与高度

| 项 | 建议 |
|---|---|
| 网格 | 2m 模块 |
| 模块面数 | 1–5k tris |
| 贴图 | 128–256px；点采样；32–64 色板 |
| 光照 | 烘焙/顶点色；flat/ramp；无 PBR |
| 高度 | 台阶/桥/悬崖/高低差；边缘高亮/阴影 |
| 遮挡 | 屋顶/树冠/高墙淡出；角色轮廓保留 |
| 可破坏 | 箱子/桶/机关；碎片/VFX 像素化 |
| 氛围 | 暖色/局部对比；避免高频噪点 |

**高度表达**：
- 影子/落点预览/高度条；跳跃/击飞时角色缩放/影子变化。
- 悬崖/台阶边缘高亮；坠落/边界清晰。
- 不要用纯视觉高度差做判定；判定用服务器高度状态。

---

## 7. VFX 与 UI

### 7.1 VFX

- 像素 sprite 64–128px；8–12 帧；点采样；有限色板。
- 预警：地面圈/扇形/直线；红=即伤、黄=延迟、蓝=可反制；窗口 0.5–1.5s；Boss 大招全屏提示。
- 命中：命中停顿/屏震/闪白/伤害数字；不要遮住角色/预警。
- 高度：落地/击飞/浮空特效；影子/高度条。
- 性能：池化/合批；同屏粒子上限；低配降级。

### 7.2 UI

- 像素字体（可读性优先）；9-slice；高分辨率画布。
- 键盘提示：Z/X/C/V、Z+C/Z+X、C+X、Z+方向+C/X、Z+X+C、F、Q/Tab、+/-；UI 不依赖鼠标光标（鼠标可选时显示）。
- 色盲：形状/图标/文字辅助；不要只靠红绿。
- 缩放/字号/屏幕震动开关；手柄提示预留。
- HUD：HP/MP/架势/必杀槽/冷却/目标/队友/小地图/连段数。

## 8. 管线

```text
概念（AI 辅助/手绘）
  → Blockbench/Blender 低模
  → Aseprite/Substance 像素贴图
  → Unity URP 导入
  → 导入校验（面数/贴图/色板/骨骼/插槽/命名）
  → Addressables 分包
  → 风格/可读性/性能验收
```

- 共享骨架；按武器原型复用动画；装备模块化。
- 命名规范：`chr_/wpn_/arm_/core_/env_/vfx_/ui_` + 版本。
- 贴图：点采样/无压缩或 BC7；色板/材质统一。
- 外包：规范/参考/验收/版本管理；AI 只做概念/变体/占位。
- 来源/许可登记；AI 生成标注；不复制竞品资产。

## 9. 资产预算（估算）

**数量**：EA 1 角色/4 武器/6 核心 VFX/10 防具/15 敌人/2 Boss/1 野外/2 副本/2 PvP/1 城镇/30 外观；1.0 1/8/12/20/30/5/2/4/3/1 + 80 外观（含在角色/装备/动画人月）。

**人月量级**（±30%，含返工/技术美术/外包管理）：

| 内容 | EA 人月 | 1.0 人月 |
|---|---|---|
| 角色/装备/动画 | 12–30 | 25–60 |
| 敌人/Boss | 8–20 | 15–40 |
| 环境/关卡 | 8–20 | 15–40 |
| VFX/UI/技术美术 | 5–15 | 10–30 |
| 合计 | 33–87 | 65–174 |

- 分项加总为 33–85 / 65–170；C6 详细估算约 87/174；合计取二者上限 33–87 / 65–174，覆盖 Research B 估算（约 28–32/60–65）的差异。差异来自是否含全套动画、外包返工、环境量、Boss 复杂度；M0 风格测试后按实测单位人月重估。
- 4–6 名美术 + 30–50% 外包，可在 18–24 个月内容纳；预算门 Human 批准。
- 共享骨架/模块化/调色变体/按武器原型复用降本；预算不含音频/本地化/市场素材。

## 10. 风格测试

**目标**：在量产前验证“2.5D 斜俯视 + 3D 低多边形 + 像素贴图”是否成立。

**范围**：1 角色 + 1 环境（含高低差/遮挡）+ 3 套装备 + 1 Boss + 1 套 VFX/UI。

**测试**：
1. 6/10/14m 战斗可读性：角色/装备/敌人/预警是否清楚；20/30m 只测战术轮廓。
2. 斜俯视剪影：帽子/肩甲/武器/披风是否可辨。
3. 高度/遮挡：跳跃/击飞/台阶/屋顶淡出是否可读。
4. 3D low-poly vs 2D billboard 对比：成本/可读性/风格。
5. 性能：同屏 20 角色/4 敌人/特效；1080p60 目标。
6. 玩家测试：10–20 人，能否认出装备/躲开预警/找到自己。

**通过标准**（与 `docs/02` §3.1 可读性验收一致）：
- 6m ≥90%、10m ≥85%、14m ≥80%：战斗可读性（发货相机视口内）。
- 20/30m：zoom-out size 15/23，仅战术/轮廓 ≥70%，不作战斗验收。
- 3D vs billboard：识别率差距 ≤10%，成本 ≤0.5×。
- 性能：1080p60 @ GTX 1060/RX 580。
- Art Lead/Human 认可风格方向。

**不通过**：调相机/贴图/剪影/描边；仍不通过则改 2D billboard 或更卡通渲染。

## 11. Do / Don't

### Do
- 先做剪影/色块，再画细节。
- 用有限色板；阴影带颜色；避免纯黑纯白。
- 贴图内画光影/AO；flat/ramp；无 PBR。
- 6/10/14m 测试 + 20/30m 战术；预警优先。
- 共享骨架/模块化/按武器原型复用。
- 角色/装备/敌人用颜色/形状区分。

### Don't
- 不要全屏像素化正常 3D。
- 不要 voxel 作为默认（成本/剪影）。
- 不要高频噪点/过度细节（俯视看不清）。
- 不要纯黑纯白/过度 PBR。
- 不要让 VFX 遮住预警/角色。
- 不要每件装备独立动画（成本爆炸）。
- 不要复制竞品资产/角色/UI。

## 12. 风险与开放问题

| 风险 | 对策 |
|---|---|
| 斜俯视剪影不清 | 剪影规则/描边/rim light/颜色语言；6/10/14m + 20/30m 战术测试 |
| “像糊掉的 3D” | 贴图当插画/有限色板/点采样/阶梯动画；风格测试 |
| 资产成本/外包不一致 | 模块化/共享骨架/导入校验/外包规范 |
| 高度/遮挡误判 | 影子/落点预览/边缘高亮/遮挡淡出 |
| AI 生成版权/风格不一致 | 只做概念/占位；标注；Art Lead 验收 |
| 性能 | 面数/贴图/粒子预算；池化/合批/LOD |

**开放问题**：
- 正交 vs 低 FOV 透视（风格测试）。
- 角色 2.5 还是 3 头身。
- 描边粗细/颜色。
- UI 像素字体选型。
- 外包比例/团队配置。
