# 2D 纸娃娃样张计划与改动影响

> 结论：**不是整个项目重做**。相机/输入/移动/Hot.Sim/HUD/联网方案基本复用；主要是 **角色表现层 + 装备装配 + 美术资产管线** 换成 2D 纸娃娃。是否最终切 2D，等样张评审。

## 1. 复用 vs 重做

| 模块 | 影响 | 说明 |
|---|---|---|
| 相机/URP/场景 | **复用** | 固定正交 2.5D 相机不变；2D 层用 billboard/quad 或 SpriteRenderer |
| 输入/移动/跳跃/双击跑 | **复用** | `PlayerMotor` 逻辑可保留；角色朝向→方向 sprite |
| Hot.Sim 战斗核心 | **复用** | U1 核心/伤害/防御/技能/必杀与表现层解耦 |
| U1b bridge/HUD | **小改** | 资源/技能状态复用；HP 条/动画表现换 2D |
| 3D 角色 KayKit/Animator | **替换** | 不再用 3D skin/Animator；2D 层用 SpriteRenderer + 帧动画 |
| 3D 装备/AvatarEquipmentController | **重做** | 层排序/挂点/换装逻辑重写；slot 概念复用 |
| UGC 纹理 | **重定义** | 3D 固定 UV → 2D 每层贴图/调色板/模板；审核/存储可复用 |
| 美术资产/动作 | **重做/扩产** | 4 向 × 动作 × 层；AI 生成 + 清理/对齐 |
| 文档/ADR | **更新** | ADR-010 暂不取代；样张通过后才切基线 |
| Fusion/后端/Steam | **复用方案** | 与表现层无关；2D 不改变服务器权威/传输 |

**代码层**：大规模重写集中在 `CharacterAnimationDriver`、`AvatarEquipmentController`、KayKit 装配；核心战斗/输入/相机不动。  
**资产层**：这是主要成本；AI 能出层，但需要 Aseprite/脚本清理、4 向对齐、分层排序。

## 2. 样张范围

- 1 个基础身体 + `hair_01` + `top_01` + `weapon_sword_01`。
- 先 **4 向 S/E/N/W**；idle + walk；通过后再扩 run/attack。
- 层级：`base → bottom → top → hair → weapon`。
- 同 canvas/脚底 pivot/帧号；78px 身高可读；6/10m 可辨。
- 独立场景/独立路径，不替换当前 U0 主场景。

## 3. 资产规格

- 64×64 first（PixelLab animation 支持 64）；后续可 96×96。
- 透明背景，无抗锯齿，≤32 色。
- 每层独立 PNG；命名 `hot_blade_01_<dir>_<anim>_<frame>.png`。
- hair 必须去掉脸/头残留；top/shoes 不能带身体。
- 先手工对齐 4 向；不要直接批量生成 8 向。

## 4. 实施步骤

1. PixelLab：base_body 4 向 + hair/top 4 向（或先用 front/back 两向验证）。
2. 清理：Aseprite/脚本去背景、去脸、统一色板、脚底 pivot。
3. Unity：`PaperdollAvatar`（SpriteRenderer 层）+ `PaperdollAnimator`（帧驱动） + 独立 `PaperdollSample.unity`。
4. 接入移动/朝向/武器挂点；先只演示 idle/walk。
5. 评审：78px 可读性、换装、武器跟随、UGC 层替换。
6. 决策：通过 → 新 ADR 取代 ADR-010；不通过 → 回 3D 模块化（ADR-013）。

## 5. 风险

- 4/8 向 × 动作 × 层资产量；AI 层间一致性/对齐仍要人工。
- 2D 层遮挡/排序/武器挂点；斜俯视下脚底对齐。
- UGC：玩家“画衣服纹理”在 2D 层里语义不同，需要模板/调色板/审核。
- 2D billboard 与 3D 场景/阴影/遮挡融合；需要样张验证。
- 如果最终切 2D，现有 3D 角色资产/装配代码会废弃，但不影响玩法/联网/文档主体。

## 6. 验收门

- [ ] 4 向 idle/walk 可拼装，无头/脸/身体穿帮。
- [ ] 78px 身高可读，武器/头发/衣服可辨。
- [ ] 换 hair/top/weapon 不破坏 pivot/动作。
- [ ] 1 个 UGC 层替换测试。
- [ ] Human 判断是否值得切换 2D。
