TASK-062 键盘 rollover / 组合人工测试

单文件页面，无需服务器 / 无需联网。用于在真实键盘上验证 Z/X/C/方向 组合能否被系统与浏览器同时识别。 本页只测试「OS/浏览器实际收到的按键」，不能区分硬件 ghosting 与软件过滤，也不能替代硬件矩阵测试。

使用说明（请先读完）

  1. 用 Chrome / Edge / Firefox 双击打开本文件（file://），不需要服务器。
  2. 至少测试 2–3 把不同键盘：一把全键无冲（NKRO）、一把标称 6KRO 的游戏键盘、一把办公薄膜/笔记本键盘（常见为 2KRO 级别）。每把键盘测试前点「重置全部」或重新打开页面。
  3. 关闭 Windows「粘滞键 / 筛选键 / 切换键」，输入法切到英文，不要用远程桌面 / 虚拟机 / 云电脑；必须用真实键盘物理按键，不要用 AutoHotkey、脚本或 DevTools 合成事件。
  4. 在「组合同时按住测试」里点某行「开始」，然后同时按住该组合要求的键（方向组合先按住方向），页面会自动判定并显示观察到的最大同时按键数；按不出来时点「结束」，该行记为不通过。
  5. 在「顺序输入回退测试」里点「开始」，按提示先按后放完成顺序输入；页面显示总时长，≤250ms 为通过。该测试模拟低 rollover 键盘的软件回退输入。
  6. 顶部「实时状态」可自由按压任意键，观察按下键列表与同时键数；点「重置最大值」清零会话最大值。
  7. 最后填写键盘信息 →「生成报告」→「下载报告」，把每把键盘的报告交回 TASK-062 汇总。
重要：本页只反映 OS/浏览器把哪些按键交给了网页。它无法区分硬件 ghosting/防冲、键盘固件过滤、OS 粘滞键/筛选键、远程桌面或浏览器快捷键吞键； 也不能代替引擎输入层实测。页面用 DevTools/自动化合成的事件没有硬件证据意义。 判定规则页只用于「显示最近组合」，不代表游戏引擎的最终判定。
键位假设：QWERTY 物理键位（Z/X/C/V），方向键支持 ↑↓←→ 与 WASD（WASD 会显示为方向）。Shift 视为修饰键，不计入「非修饰键同时按数」。
